# Short Answer Exam

Only short-answer topics are kept here. Multiple-choice answers and source indexes are excluded.

## Frequency 4

### Internet Checksum

Use one's complement addition on 16-bit words, wrap any carry back into the low 16 bits, then invert the final sum.

### Hamming Distance / Hamming Code

The Hamming distance of a code space is the minimum pairwise distance between codewords. It can detect up to `d - 1` errors and correct up to `floor((d - 1) / 2)` errors, where `d` is the minimum distance.

### NAT

NAT rewrites private internal IP addresses, usually together with ports, into a public IP and port at the network edge. It lets many private hosts share one public IPv4 address.

### Latency

Latency is the sum of transmission delay and propagation delay.

```text
Transmission delay = message size / bandwidth
Propagation delay  = distance / propagation speed
Latency            = transmission delay + propagation delay
```

### Switch Learning / Backward Learning / Ethernet Switching

A switch works at the data link layer. It learns `source MAC -> incoming port` from arriving frames, then forwards later frames using the destination MAC. Unknown destinations are flooded.

### Symmetric vs Asymmetric Encryption

Symmetric encryption uses one shared secret key, so it is fast but has a key distribution problem. Asymmetric encryption uses a public/private key pair, which solves key distribution but is slower and usually used to establish a shared symmetric session key.

## Frequency 3

### Hub / Switch / Router

A hub operates at the physical layer and repeats signals to all ports. A switch operates at the data link layer and forwards frames using MAC addresses. A router operates at the network layer and forwards packets using IP addresses and routing tables.

### ARQ Stop-and-Wait

The sender sends one frame and waits for an ACK. If the ACK is missing or lost, a timeout triggers retransmission. Sequence numbers prevent duplicate delivery.

### ARP

ARP maps an IP address to a MAC address on the local link. The sender broadcasts an ARP Request, the target replies with its MAC, and the sender caches the mapping.

### IP vs MAC Addresses

IP is a logical, end-to-end network-layer address used by routers. MAC is a local link-layer address used by switches for hop-by-hop frame delivery.

### IPv4 Fragmentation / MTU / Path MTU Discovery

IPv4 routers may fragment packets and the destination host reassembles them. IPv6 routers do not fragment; the source should send a size that fits the path, usually using Path MTU Discovery.

### Public Key Encryption

Public key cryptography uses a public/private key pair. The public key can be shared openly; only the private key can decrypt or sign, which resolves the key distribution problem.

## Frequency 2

### DNS Resolution

The client asks a local DNS server. If the answer is not cached, the local server queries root, TLD, and authoritative servers, then caches and returns the final IP address.

### Hidden Node / Exposed Node

Hidden nodes cannot hear each other but can both reach the same receiver, so their frames may collide. Exposed nodes hear a nearby transmission and stay silent even when their own transmission would not interfere. RTS/CTS helps by reserving the channel more precisely.

### ICMP

ICMP is a network-layer support protocol for error reporting and diagnostics. Common uses include `Destination Unreachable`, `Time Exceeded` for traceroute, and `Echo Request/Reply` for ping.

### Proxy Caching / CDN

Proxy caching places a cache between clients and servers so repeated requests can be served locally. A CDN is a distributed set of replica servers placed near users to reduce latency and origin load.

### Link-State Packet

A link-state packet describes a router’s neighbours and link costs. Routers flood LSPs, build the same topology map, then run Dijkstra to fill the forwarding table.

### Routing vs Forwarding

Routing computes paths and builds the table. Forwarding is the local per-packet action of sending a packet to the next hop using that table.

### Per-hop IP / MAC / Port

Ports and IP addresses are usually end-to-end, except when NAT changes them. MAC addresses change at every hop because each link needs a new frame header for the next local delivery.

## Frequency 1

### VLAN Port Assignment

VLANs create separate logical LANs on the same physical switch. Put hosts that should communicate in the same VLAN, and separate groups that should not communicate into different VLANs.

### Full-Duplex vs Half-Duplex

Full-duplex allows sending and receiving at the same time. Half-duplex allows communication in both directions, but only one direction at a time.

### IPv4/IPv6 Tunnels

Tunnelling carries IPv6 packets inside IPv4 packets so they can cross IPv4-only infrastructure. The tunnel endpoints add and remove the outer IPv4 header.

### Narrow Waist of the Internet

IP is the common middle layer of the Internet. Many applications and transport protocols sit above it, and many link technologies sit below it.

### Passband Modulation

Passband modulation sends data by modifying a carrier signal, usually its amplitude, frequency, or phase. It is used when the channel cannot directly carry baseband signals.

### QAM

QAM combines amplitude and phase to encode bits in a symbol. `QAM-16` carries 4 bits per symbol, and `QAM-64` carries 6 bits per symbol.

### DNS Spoofing

DNS spoofing injects a fake DNS reply so a name resolves to the attacker’s IP. Without DNSSEC or strong authentication, the false answer may be trusted and cached.

### TCP Three-Way Handshake

TCP establishes a connection with `SYN`, `SYN+ACK`, and `ACK`. This synchronises initial sequence numbers and creates connection state on both ends.

### Flow Control

Flow control prevents the receiver’s buffer from overflowing. TCP uses an advertised receive window to tell the sender how much data it may have outstanding.

### IPv4 Prefix Range

For a prefix such as `192.162.0.0/12`, find the block size from the mask and compute the first and last addresses covered by that prefix.
