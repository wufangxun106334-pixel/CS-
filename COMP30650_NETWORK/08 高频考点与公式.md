## 2. 高频公式

### Transmission Delay

`Transmission delay = Message size / Bandwidth`

### Propagation Delay

`Propagation delay = Distance / Propagation speed`

### Basic Total Latency

`Total latency ≈ Transmission delay + propagation delay`

### Subnet / Prefix

- `/n` 的 IPv4 地址总数：`2^(32-n)`
- 普通主机子网的可用地址数：`2^(32-n) - 2`
- `/24`：总数 `256`，通常可用 `254`
- `/27`：总数 `32`，通常可用 `30`
- `/16` subnet mask：`255.255.0.0`

### QAM Bits Per Symbol

`bits per symbol = log2(number of symbols)`

- `QAM-16 = log2(16) = 4 bits/symbol`
- `QAM-64 = log2(64) = 6 bits/symbol`

bits/symbol 越高，频谱效率越高，但通常需要更高信噪比(SNR)，也更容易受噪声影响。

### Hamming Distance 能力

- 若最小距离 `HD = d + 1`，可检测 `d` 位错误
- 若最小距离 `HD = 2d + 1`，可纠正 `d` 位错误

## 3. 单位换算

- `1 byte = 8 bits`
- `1 kbps = 1000 bits/s`
- `1 Mbps = 10^6 bits/s`
- `1 Gbps = 10^9 bits/s`
- `1 s = 1000 ms`
- `1 km = 1000 m`

## 4. 高频计算例题

### Delay / Latency

| 参数 | Transmission delay | Propagation delay | Total latency |
|---|---:|---:|---:|
| `1500 bytes`, `10 Mbps`, `3000 km`, `2*10^8 m/s` | `1.2 ms` | `15 ms` | `16.2 ms` |
| `1800 bytes`, `100 Mbps`, `35000 km`, `2*10^8 m/s` | `0.144 ms` | `175 ms` | `175.144 ms` |
| `1500 bytes`, `100 Mbps`, `25000 km`, `2*10^8 m/s` | `0.12 ms` | `125 ms` | `125.12 ms` |
| `1250 bytes`, `128 kbps`, fixed delay `5 ms` | `78.125 ms` | `5 ms` | about `83.125 ms` |

做题顺序：

1. `bytes * 8` 转成 bits。
2. bandwidth 转成 bits/s。
3. `Transmission delay = bits / bits/s`。
4. distance 转成 m。
5. `Propagation delay = m / m/s`。
6. 两者相加，并把秒换成 ms。

### Internet Checksum

| Words | One's complement sum | Checksum |
|---|---:|---:|
| `0001 f4a2 c3d2 a2a4 f8d6` | `53F2` | `AC0D` |
| `A9BC 45FE A9C5 53DF` | `ED5F` | `12A0` |
| `4500 003C 1234 5678 9ABC` | `48A5` | `B75A` |

关键动作：每次超过 `FFFF`，把 carry 回卷加到低 16 位；最后对 sum 按位取反。

### CRC

接收端用 generator 对收到的 bit string 做 modulo-2 division：

- generator：`10011`
- received：`11010110110010`
- remainder：`1100`

remainder 非 0，所以 likely error。

### Subnet / Prefix

| 题型 | 结果 |
|---|---|
| `/24` 最大 IP 地址数 | `256` |
| `/24` 普通可用主机数 | `254` |
| `172.16.0.1/16` subnet mask | `255.255.0.0` |
| `10.10.10.128` 要容纳 16 nodes 的合适 prefix | `/27`，总数 32，可用 30 |
| `192.162.0.0/12` 覆盖范围 | `192.160.0.0` 到 `192.175.255.255` |

### NAT Table Translation

若 NAT 表有：

| Internal            | External            | Target             |
| ------------------- | ------------------- | ------------------ |
| `192.168.1.15:8080` | `203.0.113.5:62001` | `198.51.100.20:80` |


则：

- 出站：`192.168.1.15:8080 -> 198.51.100.20:80` 变成 `203.0.113.5:62001 -> 198.51.100.20:80`
- 入站回包：`198.51.100.20:80 -> 203.0.113.5:62001` 变成 `198.51.100.20:80 -> 192.168.1.15:8080`

### Hamming Distance / Hamming Code

Codewords:

```text
01010010
10001011
11110011
00000000
```

pairwise distances 分别是 `5, 3, 3, 4, 4, 6`，最小 `HD = 3`：

- 可检测 `2` 位错误
- 可纠正 `1` 位错误

7-bit Hamming decode 记法：

- parity positions：`1, 2, 4`
- data positions：`3, 5, 6, 7`
- syndrome 非 0 时，syndrome 的二进制值就是错误位位置

14-bit received message 要先拆成两个 7-bit blocks。

## 5. 高频辨析题

### [[概念/IP 与 MAC 地址]]

- MAC 是本地链路交付地址
- IP 是跨网络逻辑地址

### [[概念/ARP]]

- ARP 是 IP 到 MAC 的本地映射过程
- 不负责远程路径选择

### [[概念/Router 与 Switch]]

- switch 看 MAC
- router 看 IP prefix

### [[概念/Routing、Forwarding 与 Longest Prefix Match]]

- routing 是算路
- forwarding 是按表发包
- longest prefix match 选最具体前缀
- NAT 常见于 `IP + Port` 映射
-![[Pasted image 20260429233956.png]]
**Routing** creates the routes, while longest **prefix** match is the forwarding rule that selects the most specific **route** for each packet.
### [[概念/TCP、UDP 与 QUIC]]

- TCP 可靠、有序
- UDP 轻量、无连接
- QUIC 基于 UDP，现代 Web 常见

### [[03 链路层]]

- CRC 强检测，不等于通用纠错
- ARQ 依赖 ACK 与 timeout
- switch 用 backward learning 建 MAC 表
- backward learning = 根据 source MAC 学习端口映射
- spanning tree = 通过阻塞部分端口避免二层环路
- switch 看 MAC，router 看 IP prefix

## 6. 最值得背熟的流程

### 访问网页全流程

1. 输入 URL
2. DNS 解析到 IP
3. 若目标不在本地子网，确定默认网关
4. ARP 获取下一跳 MAC
5. switch 按 MAC 转发
6. router 按 IP prefix 转发
7. TCP/QUIC 建立传输
8. HTTP 请求 / 响应
9. HTTPS 时再叠加 TLS 保护
