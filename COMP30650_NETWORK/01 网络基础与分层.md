## 2. 网络是什么

### 中文

网络是一个由自治节点组成、能够交换信息和共享资源的互联系统。

### English

A network is an interconnected collection of autonomous nodes that can exchange information and share resources. 

### 关键词

- `node` 节点
- `host / end system` 主机 / 端系统
- `router` 路由器
- `switch` 交换机
- `link` 链路

## 3. 网络组件中英对照

| English | 中文 | 作用 |
|---|---|---|
| Host / End System | 主机 / 端系统 | 运行应用、产生和接收数据 |
| Router | 路由器 | 跨网络转发 packet |
| Switch | 交换机 | 在局域网内按 MAC 转发 frame |
| Link | 链路 | 连接节点的物理或逻辑通道 |
| Application | 应用 | 使用网络服务 |
| Protocol | 协议 | 规定通信规则 |

## 4. Protocol 协议

协议至少包含三件事：

- `Syntax` 语法：消息长什么样
- `Semantics` 语义：字段是什么意思
- `Actions` 行为：收到消息后怎么处理

这也是为什么 [[概念/ARP]]、[[概念/DHCP]]、[[概念/TCP、UDP 与 QUIC]] 都属于协议，只是所处层次不同。

## 5. Layering 分层

分层是为了解决复杂性。

### 好处

- 模块化 `modularity`
- 信息隐藏 `information hiding`
- 便于替换实现
- 便于复用下层服务

### 代价

- 头部开销 `overhead`
- 上层可能看不到下层细节

## 6. Topology 拓扑

| Topology | 中文 | 优点 | 缺点 |
|---|---|---|---|
| Bus | 总线型 | 成本低、布线简单 | 主干故障影响大、扩展性差 |
| Ring | 环型 | 发送有序、冲突少 | 单点故障影响整体 |
| Star | 星型 | 易管理、易隔离故障 | 中心设备故障影响全网 |
| Mesh | 网状 | 冗余高、可靠性强 | 成本高 |
| Tree | 树型 | 易扩展、分层管理 | 依赖骨干 |

### LAN / WAN / MAN / PAN

| 类型  | 范围      | 典型例子                                               |
| --- | ------- | -------------------------------------------------- |
| PAN | 个人范围    | Bluetooth / personal devices                       |
| LAN | 小范围本地网络 | home network, lab network, office Ethernet / Wi-Fi |
| MAN | 城市范围    | city network                                       |
| WAN | 大范围网络   | ISP backbone, country/global network               |

考试里如果问“limited to a small geographical area”，通常选 `LAN`。

### 常见设备快速区分

| Device          | 中文       | 典型层次               | 核心作用                           |
| --------------- | -------- | ------------------ | ------------------------------ |
| Hub             | 集线器      | Physical / Link 边界 | 收到信号后广播到所有端口，不学习 MAC           |
| Repeater        | 中继器      | Physical           | 再生/放大信号，延长链路距离                 |
| Switch / Bridge | 交换机 / 网桥 | Link               | 按 MAC 在 LAN 内转发 frame          |
| Router          | 路由器      | Network            | 按 IP prefix 在不同网络之间转发 packet   |
| Modem           | 调制解调器    | Physical           | digital 与 analogue signal 之间转换 |
| Firewall        | 防火墙      | 多层都可能              | 按策略过滤或阻断流量                     |

易错点：

- hub 不会学习 MAC table，通常是广播式转发。
- bridge 和 switch 都是二层转发设备，switch 可以看作多端口 bridge。
- modem 的关键词是 `modulation / demodulation`，不是 routing。

### Simplex / Half-duplex / Full-duplex

| Mode | 含义 | 例子 |
|---|---|---|
| Simplex | 只能单方向发送 | 单向广播信道 |
| Half-duplex | 双向都能发，但同一时刻只能一个方向 | 对讲机式通信 |
| Full-duplex | 双向可同时发送 | 现代 switched Ethernet |

半双工题目常见说法：`bidirectional, but one direction at a time`。

## 7. 网络要帮应用完成什么

- 建立连接 `connection establishment`
- 释放连接 `connection release`
- 找路径 `find a path`
- 可靠传输 `reliable delivery`
- 共享带宽 `share bandwidth`
- 保护数据 `secure information in transit`

## 8. 易错点辨析

### 易错 1：协议和层是一个东西

不是。

- 协议是“同层实体之间的通信规则”
- 层是“系统纵向组织结构”

### 易错 2：分层越多越好

不是。

分层太细会增加开销，也可能隐藏重要信息。

### 易错 3：所有网络设备都做同一种转发

不是。

- `switch` 主要转发 frame，看 MAC
- `router` 主要转发 packet，看 IP / prefix

详见 [[概念/Router 与 Switch]]。
