# Obsidian Vault

This repository is organized to keep the note content stable while ignoring local Obsidian state that changes constantly.

## Layout

- `COMP30650_NETWORK/`, `COMP30660 Arch架构/`, `COMP30820_Java/`, `COMP47350_DataAnalysis/`: course note folders
- `*/Assets/`: course-specific attachments and pasted images
- `.obsidian/`: shared vault settings that are useful to sync

## Sync rules

- Keep note content and attachments in git
- Ignore transient UI state such as workspace layout and cache files
- Prefer stable filenames for pasted images and other attachments

## Notes

The vault keeps course folders at the top level because that matches how the notes are already written and linked.
