### Question 1

A data scientist is working on a dataset of 500 insurance claims. After running `df.describe()`, they notice that the `ClaimAmount` column has a mean of 8,500 but a median (50%) of 3,200. Which of the following is the most likely explanation and recommended next step?

A. The data is normally distributed; no action is needed.

B. The data is likely right-skewed with potential outliers; a boxplot should be plotted to investigate.

C. The mean and median are always different; this is not a data quality issue.

D. The median is incorrect and should be recalculated.


**Answer:** B

The mean is much larger than the median, so the distribution is likely right-skewed and may contain outliers. A boxplot is the right next step to inspect the spread and potential extreme values.

### Question 2

A logistic regression model is trained to detect fraudulent insurance claims. The confusion matrix on the test set is:

|  | Predicted: Fraud | Predicted: Not Fraud |
|---|---|---|
| **Actual: Fraud** | 40 | 10 |
| **Actual: Not Fraud** | 15 | 135 |

What is the **Recall** of this model?

A. 0.727

B. 0.800

C. 0.844

D. 0.900


**Answer:** B

$$Recall = \frac{TP}{TP + FN} = \frac{40}{40 + 10} = 0.800$$

### Question 3

A data scientist builds a random forest model on the Offices dataset (10 samples). The in-sample accuracy is 100%, but the 5-fold cross-validation accuracy is only 62%. Which of the following best describes this situation?

A. The model is underfitting and needs more features.

B. The model is overfitting; it memorised the training data but does not generalise well.

C. The cross-validation procedure is incorrectly implemented.

D. The model is performing optimally; 62% is a good accuracy for this dataset.


**Answer:** B

100% in-sample accuracy but only 62% cross-validation accuracy is a classic sign of overfitting: the model memorised the training data but does not generalise well.

### Question 4

A dataset has a feature `EnergyRating` with categories A, B, C, and D. When applying One-Hot Encoding for a linear regression model, a data scientist sets `drop_first=True`. How many new binary columns are created, and why?

A. 4 columns — one for each category.

B. 3 columns — to avoid the Dummy Variable Trap (perfect multicollinearity).

C. 1 column — to save memory.

D. 2 columns — because only two categories are useful.


**Answer:** B

With 4 categories, `drop_first=True` creates 3 binary columns. One category is left out as the reference level to avoid the dummy variable trap and perfect multicollinearity.

### Question 5

A data scientist applies Min-Max Normalisation to a feature with values `[15, 18, 12, 210, 20, 15]`, scaling to `[0, 1]`. What problem will occur?

A. All values will be scaled to 0.

B. The normal values (12–20) will be compressed into a very narrow range near 0, because the extreme value 210 dominates the scaling.

C. The value 210 will be treated as missing and removed.

D. Min-Max Normalisation is immune to outliers and will produce a uniform distribution.


**Answer:** B

The outlier 210 dominates the min and max, so the normal values between 12 and 20 get compressed into a very narrow range near 0. Min-Max Normalisation is highly sensitive to outliers.

### Question 6

You are given a dataset of used cars with features: `Mileage`, `EngineSize`, `FuelType` (Petrol/Diesel/Electric), and target `Price`.

**(a)** Explain why `FuelType` cannot be directly used as input to a linear regression model and describe the correct encoding approach. What happens if you use integer encoding (e.g., Petrol=1, Diesel=2, Electric=3)? **(3 marks)**

**(b)** The dataset contains 200 cars, but only 8 are Electric. Discuss two potential issues this class imbalance could cause and suggest one strategy to address each. **(4 marks)**

**(c)** A colleague suggests scaling all features using Min-Max Normalisation before training. Explain why Z-Score Standardisation might be a better choice if the `Mileage` feature contains extreme outliers. Support your answer with a brief numerical illustration. **(3 marks)**


**Suggested answer:**

**(a)** `FuelType` is **categorical**, so it cannot be used directly in linear regression because the model would treat the codes as **ordered** **numbers**. Use One-Hot Encoding, and usually drop one category to avoid multicollinearity. Integer encoding such as Petrol=1, Diesel=2, Electric=3 is wrong because it creates a fake **ordering** and **distance** between categories.

**(b)** First, the model may become biased toward the majority classes, so Electric cars may be predicted poorly. Second, metrics such as accuracy can look good while minority-class recall is weak. A good fix is **stratified** sampling or class weighting/oversampling for the Electric class.

**(c)** Min-Max Normalisation is **sensitive** to extreme **outliers**, because the max value controls the whole scale. Z-Score Standardisation is often better when `Mileage` has outliers because it centres the **feature** at 0 and scales by standard deviation. For example, if most mileages are around 20,000 but one car has 200,000, Min-Max will squeeze the normal cars close together, while Z-scores still preserve more useful spread.

### Question 7

A hospital deploys a logistic regression model to predict whether a patient has a rare disease (positive class). The dataset has 950 healthy patients and 50 diseased patients. The model achieves 96% accuracy on the test set, but the medical team is unhappy with its performance.

**(a)** Explain why 96% accuracy is misleading in this scenario. Calculate what the accuracy would be if the model simply predicted "healthy" for every patient. **(3 marks)**

**(b)** The confusion matrix shows TP=30, FN=20, FP=10, TN=940. Calculate Precision, Recall, and F1-Score. Based on these metrics, explain why the medical team might prefer a model with higher Recall even if Precision drops. **(5 marks)**

**(c)** Describe how adjusting the classification threshold from 0.5 to a lower value (e.g., 0.2) would affect Recall, Precision, and the number of False Negatives. Use a brief cost-based argument: if a missed disease (FN) costs €50,000 in delayed treatment and a false alarm (FP) costs €500 in unnecessary tests, calculate the total cost for the confusion matrix in part (b) and explain why lowering the threshold would likely reduce total cost. **(2 marks)**


**Suggested answer:**

**(a)** 96% accuracy is misleading because the data is highly **imbalanced**. If the model predicted “healthy” for every patient, accuracy would already be $950/1000 = 95\%$, so 96% is only a tiny improvement over a useless majority-class baseline.

**(b)** $Precision = \frac{TP}{TP+FP} = \frac{30}{30+10} = 0.75$; $Recall = \frac{TP}{TP+FN} = \frac{30}{30+20} = 0.60$; $F1 = \frac{2PR}{P+R} = \frac{2\times0.75\times0.60}{0.75+0.60} \approx 0.667$. The medical team may prefer higher Recall because missing a diseased patient (FN) is much more dangerous than sending a healthy patient for an extra test (FP).

**(c)** Lowering the threshold from 0.5 to 0.2 usually increases Recall, decreases Precision, and reduces False Negatives because more cases are labelled positive. The current cost is $20×50{,}000 + 10×500 = €1{,}005{,}000$. Since FN is far more expensive than FP, lowering the threshold usually reduces total cost even if FP rises.

### Question 8

A data scientist is building a linear regression model to predict office rental prices using features: `Size` (square feet, range 200–5000), `Floor` (1–30), and `BroadbandSpeed` (Mbps, range 10–1000). The initial model has R² = 0.45 on the test set.

**(a)** Explain what R² = 0.45 means in business terms. If a baseline model that always predicts the mean rental price has R² = 0, what does this tell you about the model's performance relative to the baseline? **(3 marks)**

**(b)** A colleague suggests adding a feature `Size²` (Size squared) to the model. Explain why this might improve R², and clarify the apparent contradiction: how can a "nonlinear" feature be used in a "linear" model? **(3 marks)**

**(c)** After adding `Size²`, the training R² increases to 0.98, but the test R² drops to 0.35. Diagnose this problem using the Bias-Variance Tradeoff framework. Suggest two concrete solutions to address this issue. **(4 marks)**


**Suggested answer:**

**(a)** $R^2 = 0.45$ means the model explains 45% of the **variation** in rental prices, while 55% remains unexplained. Compared with the baseline model that always predicts the mean ($R^2=0$), this model is better, but it still leaves **substantial** room for improvement.

**(b)** Adding `Size^2` can improve performance because it lets the model capture curvature, such as prices rising faster for larger offices. The model is still “linear” in the machine learning sense because it is l**inear in the coefficients**: $\hat{y} = w_0 + w_1x + w_2x^2$. The inputs are **nonlinear**, but the **parameterisation** remains linear.

**(c)** Training $R^2$ rising to 0.98 while test $R^2$ drops to 0.35 is **overfitting**: low bias, high variance. Two good fixes are Ridge/Lasso regularisation and **reducing** model **complexity**, for example by removing the squared term or using cross-validation to choose a simpler model.

### Question 9

A data science team is building a classification model to predict whether employees will leave the company (attrition). The dataset has 1000 employees, 200 of whom left (positive class). The team uses a Random Forest classifier.

**(a)** Describe the complete CRISP-DM process the team should follow, from Business Understanding through to Deployment. For each of the 6 phases, provide one specific action relevant to this employee attrition scenario. **(6 marks)**

**(b)** The team builds a Decision Tree with no depth limit. The in-sample accuracy is 100%, but the hold-out test accuracy is 65%. Explain this result using the concepts of Bias and Variance. Then explain how a **Random** Forest addresses this problem through **Bagging** (Bootstrap Aggregating) and feature sampling. Why does this reduce Variance? **(5 marks)**

**(c)** The team evaluates the Random Forest using three methods:

| Method | Accuracy |
|---|---|
| In-sample | 98% |
| Hold-out (single 70/30 split) | 72% |
| 5-fold Cross-Validation | 70% ± 4% |

Explain why the Cross-Validation result is the most trustworthy. The team then compares two models:

| Model               | CV Accuracy |
| ------------------- | ----------- |
| Random Forest       | 70% ± 4%    |
| Logistic Regression | 68% ± 6%    |

Can the team confidently conclude that the Random Forest is better? Explain your reasoning with reference to the confidence intervals. **(4 marks)**


**Suggested answer:**

**(a) CRISP-DM steps:**
- **Business Understanding:** define attrition cost and what success means for HR.
- **Data Understanding:** inspect class balance, missing values, and basic patterns in the employee data.
- **Data Preparation:** clean the data, encode categorical features, and handle missing values.
- **Modelling:** train and tune a Random Forest, ideally with cross-validation.
- **Evaluation:** check confusion matrix, Recall, Precision, and F1 rather than accuracy alone.
- **Deployment:** monitor performance over time and retrain if employee behaviour changes.

**(b)** A full-depth Decision Tree can **memorise** the training set, so it has **low bias but high variance**. Random Forest reduces this by **training** many trees on **bootstrap** samples and random feature **subsets**. That makes the trees less correlated, so averaging their predictions cancels out some of the individual tree noise and lowers variance.

**(c)** CV is more trustworthy because it uses **multiple train-validation splits** and averages the results, so the estimate is **less** **dependent** on one **random** split and better reflects generalization.. For the comparison, Random Forest is about $70\% \pm 4\%$ and Logistic Regression is about $68\% \pm 6\%$. The intervals overlap ([66%, 74%] vs [62%, 74%]), so we cannot confidently say the Random Forest is truly better without more evidence or a statistical test.

### Question 10

A data scientist is building a logistic regression model to predict whether a customer will churn (leave a subscription service). The dataset contains features: `MonthlyCharge`, `ContractLength`, `SupportTickets`, and `CustomerTenure` (months).

**(a)** The Sigmoid function is the core of logistic regression. Write the Sigmoid formula and explain how it converts a linear combination of features into a probability. If the model outputs z = -1.5 + 0.02×MonthlyCharge + 0.5×ContractLength, calculate the predicted probability of churn for a customer with MonthlyCharge=80 and ContractLength=1. Show your working. **(5 marks)**

**(b)** After training, the model produces the following coefficients:

| Feature        | Coefficient |
| -------------- | ----------- |
| Intercept      | -2.1        |
| MonthlyCharge  | 0.03        |
| ContractLength | -1.8        |
| SupportTickets | 0.4         |
| CustomerTenure | -0.05       |

Interpret each coefficient in terms of Log-Odds and Odds. For `ContractLength`, calculate the Odds Ratio and explain its business meaning: if a customer moves from a 1-month contract to a 12-month contract, how does their churn Odds change? **(5 marks)**

**(c)** The team wants to add a categorical feature `PaymentMethod` with levels: Credit Card, Bank Transfer, Direct Debit. Explain how to encode this feature for logistic regression, including why `drop_first=True` is necessary. The team also considers applying L2 (Ridge) regularisation to the model. Explain what the C parameter **controls**, how it relates to the regularisation strength λ, and why **standardising** features before applying **regularisation** is important. **(5 marks)**


**Suggested answer:**

**(a)** The sigmoid formula is $$\sigma(z) = \frac{1}{1 + e^{-z}}$$. It converts any real-valued linear score into a probability in the range [0, 1]. Here, $z = -1.5 + 0.02\times80 + 0.5\times1 = 0.6$, so the predicted churn probability is $$\sigma(0.6) = \frac{1}{1 + e^{-0.6}} \approx 0.646.$$

**(b)** The intercept -2.1 is the baseline log-odds of churn when all other features are 0. `MonthlyCharge` has coefficient +0.03, so each extra unit increases log-odds by 0.03, and odds are multiplied by $e^{0.03}$. `ContractLength` has coefficient -1.8, so each extra month reduces log-odds by 1.8 and multiplies odds by $e^{-1.8} \approx 0.165$. `SupportTickets` (+0.4) increases churn odds, while `CustomerTenure` (-0.05) decreases churn odds. Moving from a 1-month to a 12-month contract multiplies churn odds by $e^{-1.8\times11} = e^{-19.8}$, which is extremely small, so longer contracts strongly reduce churn risk.

**(c)** `PaymentMethod` should be encoded with One-Hot Encoding. With three categories, drop_first=True keeps **two dummy columns** and uses the **dropped** **category** as the **baseline** to the dummy variable trap. In logistic regression, `C` controls regularisation strength and is the **inverse** of $\lambda$: smaller `C` means stronger regularisation, larger `C` means weaker regularisation. Standardising features is important because **regularisation penalises coefficient size**, and features on different scales would otherwise be penalised unfairly.

- (b) Issues: model biased toward Diesel/Petrol; Electric predictions unreliable. Strategy: stratified sampling, or collect more Electric data.

**Q8:**

- (b) $Size^2$ captures accelerating/decelerating relationship. The model is still "linear in parameters": $\hat{y} = w_0 + w_1 x + w_2 x^2$, which is linear in $(w_0, w_1, w_2)$.

### Section C (Key Points)

**Q9:**
- (a) CRISP-DM: Business Understanding (define attrition cost) → Data Understanding (EDA, check class balance) → Data Preparation (encode categoricals, handle missing values) → Modelling (Random Forest with CV) → Evaluation (F1, not just Accuracy) → Deployment (monitor model drift).
- (b) Decision Tree memorises noise → low bias, high variance. Random Forest: each tree trained on bootstrap sample (different data subset) + random feature subset → trees are decorrelated → averaging reduces variance.
- (c) CV is most trustworthy: averages over multiple splits, reduces randomness. For model comparison: RF 70%±4% → [66%, 74%]; LR 68%±6% → [62%, 74%]. Intervals overlap → cannot confidently conclude RF is better. Need more data or statistical test.

**Q10:**
- (a) Sigmoid: P(y=1) = 1 / (1 + e^(-z)). z = -1.5 + 0.02 × 80 + 0.5 × 1 = -1.5 + 1.6 + 0.5 = 0.6. P = 1 / (1 + e^(-0.6)) = 1 / (1 + 0.5488) = 0.646.
- (b) ContractLength coefficient = -1.8: each additional month decreases Log-Odds by 1.8. Odds Ratio = e^(-1.8) = 0.165. Moving from 1 to 12 months: Odds multiplied by e^(-1.8 × 11) = e^(-19.8) ≈ extremely small → much lower churn probability.
- (c) One-Hot with drop_first=True → 2 columns (e.g., Bank Transfer, Direct Debit; Credit Card as reference). C = 1 / lambda: large C = weak regularisation, small C = strong regularisation. Standardisation is essential because regularisation penalises coefficient magnitudes; without standardisation, features with larger scales would be unfairly penalised.
