# 梯度提升 (Gradient Boosting)

> 参考：Friedman (2001), XGBoost (2016)
> 核心思想：依次训练树，每棵树修正前驱树的残差误差

---

## 一、核心概念

### 什么是梯度提升

**定义**：一种集成学习方法，通过串行训练多棵决策树，每棵树都在修正前面所有树的预测误差。

### 与随机森林的根本区别

**随机森林（并行）**：
```
树1 ─┐
树2 ─┤
树3 ─┼→ 平均 → 最终预测
树4 ─┤
树5 ─┘

每棵树独立训练，互不影响
```

**梯度提升（串行）**：
```
树1 → 计算残差 → 树2 → 计算残差 → 树3 → ... → 树N
  ↓              ↓              ↓
修正误差        继续修正        继续修正

最终预测 = 树1 + 树2 + 树3 + ... + 树N（加权求和）
```

**关键思想**：
- 第1棵树：学习目标值
- 第2棵树：学习第1棵树的错误
- 第3棵树：学习前2棵树的错误
- 每棵树都在"修补"前面所有树的不足

---

## 二、训练过程详解

### 案例：房价预测

**训练数据**：

| 房子ID | 面积(m²) | 地铁距离(km) | 真实价格(万元) |
|--------|---------|-------------|--------------|
| A | 50 | 2.0 | 300 |
| B | 80 | 0.5 | 500 |
| C | 100 | 1.0 | 600 |
| D | 120 | 0.3 | 800 |
| E | 60 | 1.5 | 350 |

### 初始化

```
初始预测 f₀ = 平均价格 = (300 + 500 + 600 + 800 + 350) / 5 = 510万
```

### 第1棵树：学习目标值

**步骤1：计算残差（真实值 - 当前预测）**

| 房子 | 真实价格 | 当前预测f₀ | 残差r₁ |
|------|---------|-----------|--------|
| A | 300 | 510 | -210 |
| B | 500 | 510 | -10 |
| C | 600 | 510 | +90 |
| D | 800 | 510 | +290 |
| E | 350 | 510 | -160 |

**步骤2：训练树1预测残差**

```
树1的训练目标：预测残差 [-210, -10, +90, +290, -160]

树1学习到的规则：
  IF 面积 < 70:
      预测残差 = -185（平均A和E的残差）
  ELSE IF 面积 < 110:
      预测残差 = +40（平均B和C的残差）
  ELSE:
      预测残差 = +290（D的残差）
```

**步骤3：更新预测（加上树1的预测）**

```
学习率 η = 0.1（防止过拟合）

新预测 f₁ = f₀ + η × 树1预测

房子A: f₁ = 510 + 0.1×(-185) = 491.5
房子B: f₁ = 510 + 0.1×(+40) = 514.0
房子C: f₁ = 510 + 0.1×(+40) = 514.0
房子D: f₁ = 510 + 0.1×(+290) = 539.0
房子E: f₁ = 510 + 0.1×(-185) = 491.5
```

### 第2棵树：修正第1棵树的错误

**步骤1：计算新的残差**

| 房子 | 真实价格 | 当前预测f₁ | 新残差r₂ |
|------|---------|-----------|---------|
| A | 300 | 491.5 | -191.5 |
| B | 500 | 514.0 | -14.0 |
| C | 600 | 514.0 | +86.0 |
| D | 800 | 539.0 | +261.0 |
| E | 350 | 491.5 | -141.5 |

**步骤2：训练树2预测新残差**

```
树2学习到的规则：
  IF 地铁距离 > 1.5:
      预测残差 = -166.5（A和E的平均）
  ELSE IF 面积 > 110:
      预测残差 = +261.0（D）
  ELSE:
      预测残差 = +36.0（B和C的平均）
```

**步骤3：再次更新预测**

```
新预测 f₂ = f₁ + η × 树2预测

房子A: f₂ = 491.5 + 0.1×(-166.5) = 474.85
房子B: f₂ = 514.0 + 0.1×(+36.0) = 517.60
房子C: f₂ = 514.0 + 0.1×(+36.0) = 517.60
房子D: f₂ = 539.0 + 0.1×(+261.0) = 565.10
房子E: f₂ = 491.5 + 0.1×(-166.5) = 474.85
```

### 继续训练更多树

```
每棵树都在修正前面所有树的剩余误差

残差逐渐减小：
  初始残差：[-210, -10, +90, +290, -160]
  第1轮后：[-191.5, -14.0, +86.0, +261.0, -141.5]
  第2轮后：[-175.2, -12.4, +78.2, +234.9, -124.7]
  ...
  第100轮后：[-2.1, -0.5, +1.2, +3.5, -1.8]
```

**最终预测**：

```
f_final = f₀ + η×树1 + η×树2 + η×树3 + ... + η×树100

房子A: 300.3 ≈ 300（真实值）
房子B: 499.8 ≈ 500
房子C: 600.5 ≈ 600
房子D: 798.2 ≈ 800
房子E: 350.1 ≈ 350
```

## 三、关键参数

### 1. 学习率（Learning Rate, η）

**作用**：控制每棵树对最终预测的贡献

```
η = 1.0（激进）：
  f_new = f_old + 1.0 × 树预测
  优点：收敛快（需要的树少）
  缺点：容易过拟合

η = 0.1（保守）：
  f_new = f_old + 0.1 × 树预测
  优点：泛化能力强
  缺点：需要更多树

η = 0.01（非常保守）：
  需要数千棵树才能收敛
```

**实践经验**：
- 小学习率 + 多棵树 = 更好的泛化
- 典型值：0.01 - 0.3
- XGBoost默认：0.3

### 2. 树的数量（n_estimators）

```
与学习率的权衡：
  η = 0.3, n_trees = 100
  ≈ η = 0.1, n_trees = 300
  ≈ η = 0.03, n_trees = 1000

更多树 + 小学习率 = 更好，但训练更慢
```

### 3. 树的深度（max_depth）

```
深度 = 3（浅树，常用）：
  每棵树只能捕捉简单的模式
  需要更多树来组合
  不容易过拟合

深度 = 10（深树）：
  每棵树能捕捉复杂模式
  容易过拟合
  需要更强的正则化
```

## 四、为什么梯度提升如此强大

### 1. 逐步逼近最优解

**类比：射箭**

```
随机森林：
  10个人同时射箭，取平均位置
  每个人独立瞄准，互不影响

梯度提升：
  第1个人射箭 → 偏左10cm
  第2个人看到偏左，向右调整 → 偏左5cm
  第3个人继续调整 → 偏左2cm
  ...
  第10个人 → 几乎命中靶心

每个人都在修正前面所有人的累积误差
```

### 2. 能捕捉复杂的非线性关系

**案例：房价与面积的非线性关系**

```
真实关系（复杂）：
  面积 < 50: 价格 = 5×面积
  50 ≤ 面积 < 100: 价格 = 3×面积 + 100
  面积 ≥ 100: 价格 = 2×面积 + 200

树1学习主要趋势：
  面积 < 75: 预测 = 300
  面积 ≥ 75: 预测 = 500

树2修正细节：
  在面积50附近调整 +50
  在面积100附近调整 +100

树3、树4...继续细化

最终能完美拟合复杂的分段函数
```

### 3. 自动特征交互

```
树1可能学习：
  IF 面积 > 100: +200

树2可能学习：
  IF 面积 > 100 AND 地铁距离 < 1: +100
  （自动发现了面积和地铁距离的交互作用）

树3可能学习：
  IF 面积 > 100 AND 地铁距离 < 1 AND 房龄 < 5: +50
  （三阶交互）

不需要人工设计特征交互项！
```
