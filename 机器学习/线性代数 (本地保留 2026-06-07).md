# 线性代数核心概念

## 1. 线性组合与直线

**问题**：为什么固定一个基向量的标量，改变另一个生成的向量，新向量终点在一条直线上？

**解释**：
```
v = a0·e1 + b·e2 （a0 固定，b 变化）
```
- a0·e1 是固定点
- b·e2 沿 e2 方向伸缩
- 所有组合形成过固定点、方向为 e2 的直线

**例子**：e1=(1,0), e2=(0,1), a0=2
- v = (2, b) -> 垂直直线 x=2

---

## 2. 线性相关与张成空间

**核心关系**：

| 线性相关性 | 几何表现 | 张成空间 |
|-----------|---------|---------|
| 线性相关（共线） | 向量在同一直线上 | 一条直线（一维） |
| 线性无关（不共线） | 向量指向不同方向 | 一个平面（二维） |

**直观理解**：
- **线性相关** -> 方向信息重复 -> 只能张成低维空间
- **线性无关** -> 独立方向信息 -> 能张成更高维空间

---

## 3. 正交性与张成空间

**核心结论**：正交与否**不影响**张成空间的维度

| | 正交基 | 非正交基 |
|---|---|---|
| 张成空间 | 平面 | 平面 |
| 线性无关 | 是 | 是 |
| 坐标求解 | 简单（投影直接得） | 复杂（需解方程组） |

> **正交性解决的是"好不好用"的问题，不是"能不能张成"的问题**

---

## 4. 基（Basis）的定义

**基 = 线性无关 + 张成整个空间**

两个条件缺一不可：
- **线性无关** -> 保证没有冗余向量（不浪费）
- **张成空间** -> 保证能表示所有向量（不遗漏）

**例子**：R2 的基 {(1,0), (0,1)}
- 任意 (a,b) = a·(1,0) + b·(0,1)

---

## 5. 矩阵乘法的几何意义

**矩阵乘法 = 用新基重新表达原来的坐标**

```
A·v = x·(A的第一列) + y·(A的第二列)
```

| 部分 | 几何意义 |
|-----|---------|
| 矩阵的**列** | 变换后的新基向量 |
| 右边的向量 | 在原基下的坐标（系数） |
| 乘积结果 | 变换后的目标向量 |

**例子**：旋转 90 度
```
A = [0  -1]   （列是旋转后的新基）
    [1   0]
```

---

## 6. 矩阵乘法的运算律

### 交换律不满足：AB 不等于 BA

**原因**：变换顺序影响结果
- 先旋转再缩放 != 先缩放再旋转

### 结合律满足：(AB)C = A(BC)

**原因**：无论怎么加括号，变换执行顺序不变
- 本质是函数复合：(f o g) o h = f o (g o h)

---

## 7. 行列式（Determinant）

### 命名来源
- **英文**：Determinant（决定子）-> 决定矩阵性质
- **中文**：行列式 -> 计算涉及行和列的交叉运算

### 本质：一个值承载多重含义

| 视角 | 含义 |
|-----|------|
| **几何** | 面积/体积的缩放比例 |
| **代数** | 判断是否可逆（det不等于0 则可逆） |
| **符号** | 正负表示是否翻转方向 |
| **计算** | 行列交叉相乘的组合值 |

### 计算方式（2x2）
```
| a  b | = ad - bc
| c  d |
```

> 行列式的"行"和"列"描述的是**计算方式**，不是**几何意义**

---

## 8. 行列式与线性相关

**核心结论**：行列式 = 0 当且仅当列向量线性相关

| 行列式 | 列向量 | 几何 | 矩阵可逆性 |
|-------|-------|------|-----------|
| 不等于 0 | 线性无关 | 保持面积 | 可逆 |
| 等于 0 | 线性相关 | 压缩到低维 | 不可逆 |

### 三维例子

**行列式 = 0 的情况**：
```
A = [1  0  1]
    [0  1  1]
    [0  0  0]
```
- 第三列 = 第一列 + 第二列（线性相关）
- 三个向量都在 xy 平面上，体积被压扁到 0

**行列式 != 0 的情况**：
```
B = [1  0  0]
    [0  1  0]
    [0  0  1]
```
- 三个列向量线性无关
- 单位立方体，体积 = 1

---

## 9. 满秩（Full Rank）

### 定义

**秩（Rank）** = 矩阵中线性无关的行/列的最大数量

**满秩** = 秩达到最大可能值

| 矩阵类型 | 满秩条件 |
|---------|---------|
| m×n 矩阵 | rank = min(m, n) |
| n×n 方阵 | rank = n |

### 满秩的等价条件（方阵）

```
rank = n  ⟺  列向量线性无关
           ⟺  行向量线性无关
           ⟺  行列式 ≠ 0
           ⟺  矩阵可逆
           ⟺  列空间 = ℝⁿ
           ⟺  Ax = 0 只有零解
```

### 行不满秩 vs 列不满秩

| | 行不满秩 | 列不满秩 |
|---|---|---|
| 条件 | 行数 > rank | 列数 > rank |
| 冗余 | 行向量线性相关 | 列向量线性相关 |
| 空间压缩 | 行空间维度 < 行数 | 列空间维度 < 列数 |
| 方程组视角 | 方程之间有依赖 | 变量之间有依赖 |

**对于方阵**：行不满秩 ⇔ 列不满秩 ⇔ 不满秩 ⇔ 行列式=0

---

## 10. 零空间（Null Space）

### 定义

**零空间 Null(A)** = 所有满足 Ax = 0 的向量 x 的集合

```
Null(A) = { x | Ax = 0 }
```

### 与齐次方程的关系

**齐次线性方程 Ax = 0 的解集 = 零空间 Null(A)**

两者是同一个东西的不同表述：
- **齐次方程**：关注"解是什么"
- **零空间**：关注"解构成什么结构"

### 秩-零化度定理

```
rank(A) + nullity(A) = n

其中：
- rank(A) = 列空间的维度
- nullity(A) = 零空间的维度
- n = 列数（变量个数）
```

---

## 11. 列空间（Column Space）

### 定义

**列空间 Col(A)** = 所有可能的 Ax 的集合 = 矩阵列向量的线性组合

```
Col(A) = Span{a₁, a₂, ..., aₙ}
```

### 为什么叫"列空间"

因为 Ax 本质上是**列向量的线性组合**：
```
Ax = x₁·a₁ + x₂·a₂ + ... + xₙ·aₙ
```

### 应用

**判断方程组是否有解**：Ax = b 有解当且仅当 b 在列空间 Col(A) 中

## 12. 对偶性（Duality）

### 线性函数与点积

设有一个函数：

$$f(x, y) = 2x + 3y$$

它把二维向量 $(x, y)$ 变成一个数，所以它是：

$$f: \mathbb{R}^2 \to \mathbb{R}$$

也就是一个**线性函数**。

这个函数可以写成矩阵形式：

$$f(x, y) = \begin{bmatrix} 2 & 3 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix}$$

也可以写成点积：

$$f(x, y) = \begin{bmatrix} 2 \\ 3 \end{bmatrix} \cdot \begin{bmatrix} x \\ y \end{bmatrix}$$

为什么一样？因为两者都等于 $2x + 3y$。

### 对偶性的意思

在几何中，$\begin{bmatrix} x \\ y \end{bmatrix}$ 是一个普通向量，表示平面中的一个点或方向。

而 $\begin{bmatrix} 2 & 3 \end{bmatrix}$ 是一个**线性函数**，它的作用是：

> 输入一个向量，输出一个数。

例如输入 $\begin{bmatrix} 4 \\ 1 \end{bmatrix}$，则 $f(4, 1) = 2 \times 4 + 3 \times 1 = 11$

所以 $\begin{bmatrix} 2 & 3 \end{bmatrix}$ 不是普通方向向量，而是一个"测量器"。它测量输入向量在某个方向上的大小。

### 为什么又能看成向量？

因为在欧几里得空间里，每一个线性函数都可以由一个向量来表示。

也就是说 $f(x, y) = 2x + 3y$ 这个函数可以对应到向量：

$$\vec{w} = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$$

然后用点积表示：$f(\vec{x}) = \vec{w} \cdot \vec{x}$

这就是对偶性：

> 一个"线性函数"可以等价地看成一个"向量"。

### 几何图像

看等值线 $2x + 3y = c$，当 $c$ 取不同值时，会得到一族平行直线。

向量 $\vec{w} = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$ 垂直于这些直线。

所以 $\vec{w}$ 的作用是：
- 指出函数增长最快的方向
- 测量输入向量在这个方向上的投影大小
- 把二维向量压成一个标量

> 行向量 $\begin{bmatrix} 2 & 3 \end{bmatrix}$ 是线性函数，列向量 $\begin{bmatrix} 2 \\ 3 \end{bmatrix}$ 是它在欧几里得空间中的几何代表。矩阵乘法和点积等价，正是因为线性函数和向量之间存在这种对偶关系。

## 12.1 Hadamard 积（按元素乘法）

### 定义

**Hadamard 积**：两个相同形状的矩阵，对应位置的元素相乘

```
A ⊙ B = C
其中 C[i,j] = A[i,j] × B[i,j]
```

### 计算示例

```
A = [1  2]    B = [5  6]
    [3  4]        [7  8]

A ⊙ B = [1×5  2×6] = [5  12]
        [3×7  4×8]   [21 32]
```

### 与矩阵乘法的区别

| 运算 | 名称 | 计算方式 | 形状要求 |
|------|------|----------|----------|
| **Hadamard 积** | 按元素乘法 | 对应元素相乘 | 形状相同 |
| **矩阵乘法** | 点积 | 行×列求和 | A的列数 = B的行数 |

```
Hadamard 积（按元素）：
[1 2] ⊙ [5 6] = [1×5  2×6]
[3 4]   [7 8]   [3×7  4×8]

矩阵乘法（点积）：
[1 2] × [5 6] = [1×5+2×7  1×6+2×8]
[3 4]   [7 8]   [3×5+4×7  3×6+4×8]
```

### 代码实现

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# Hadamard 积
C = A * B
# 或
C = np.multiply(A, B)

print(C)
# [[ 5 12]
#  [21 32]]
```

### 应用场景

```
1. 图像处理：
   - 遮罩（Mask）应用
   - 图像混合

2. 神经网络：
   - Dropout（随机置零）
   - 注意力机制中的权重应用

3. 数据预处理：
   - 特征缩放
   - 归一化
```

### 数学性质

```
1. 交换律：A ⊙ B = B ⊙ A
2. 结合律：(A ⊙ B) ⊙ C = A ⊙ (B ⊙ C)
3. 分配律：A ⊙ (B + C) = A ⊙ B + A ⊙ C
4. 单位元：A ⊙ 1 = A（全1矩阵）
5. 零元：A ⊙ 0 = 0（全0矩阵）
```

### 注意事项

```
⚠️ Hadamard 积 ≠ 矩阵乘法
- 两者完全不同
- 计算结果不同
- 应用场景不同

⚠️ 形状必须相同
- 如果形状不同，NumPy 会尝试广播（Broadcasting）
- 但需要满足广播规则
```

### 可视化理解

```
A = [a₁₁  a₁₂]    B = [b₁₁  b₁₂]
    [a₂₁  a₂₂]        [b₂₁  b₂₂]

A ⊙ B = [a₁₁×b₁₁  a₁₂×b₁₂]
        [a₂₁×b₂₁  a₂₂×b₂₂]

就像把两个矩阵"重叠"，对应位置相乘
```

## 13. 叉积（Cross Product）

### 定义

**叉积**：两个三维向量的运算，结果是一个**垂直于两者的向量**

```
a = (a₁, a₂, a₃)
b = (b₁, b₂, b₃)

a × b = (a₂b₃ - a₃b₂, a₃b₁ - a₁b₃, a₁b₂ - a₂b₁)
```

### 几何意义

- **方向**：垂直于 a 和 b（右手定则）
- **模长**：|a × b| = |a|·|b|·sin(θ) = 平行四边形面积

### 主要用途

| 用法 | 公式 | 结果 |
|-----|------|------|
| 求法向量 | a × b | 垂直于 a 和 b 的向量 |
| 求面积 | \|a × b\| | 平行四边形面积 |
| 判断共线 | a × b = 0 | a 和 b 平行 |
| 力矩 | r × F | 旋转效果 |

### 与点积对比

| | 点积 a·b | 叉积 a×b |
|---|---------|---------|
| 结果 | 标量 | 向量 |
| 为零时 | a ⊥ b | a ∥ b |

### 叉积的行列式表示

**记忆形式**：

```
|i   j   k  |
|v₁ v₂ v₃|
|w₁ w₂ w₃|
```

- 第一行：标准基向量 i, j, k
- 第二行：第一个向量 v
- 第三行：第二个向量 w

**展开**：

```
= i(v₂w₃ - v₃w₂) - j(v₁w₃ - v₃w₁) + k(v₁w₂ - v₂w₁)
= (v₂w₃ - v₃w₂, v₃w₁ - v₁w₃, v₁w₂ - v₂w₁)
= v × w
```

> 这是一个**形式行列式**（第一行是向量不是标量），但展开后恰好等于叉积定义

### 叉积模长定义

```
|a × b| = |a|·|b|·sin(θ)
```

**为什么等于平行四边形面积？**

```
        b
       /|
      / |
     /  | h = |b|sin(θ)
    /   |
   /θ___|______ a

面积 = 底 × 高 = |a| × |b|sin(θ) = |a||b|sin(θ)
```

### 叉积与点积的对偶关系

| 运算 | 公式 | 几何意义 |
|------|------|----------|
| 点积 a·b | \|a\|\|b\|cos(θ) | 投影长度 |
| 叉积模 \|a×b\| | \|a\|\|b\|sin(θ) | 平行四边形面积 |

两者都是**向量夹角的三角函数 × 模长乘积**，选取不同三角函数对应不同几何量。

## 13.1 叉积与行列式的关系

### 标量三重积

**定义**：u · (v × w) = 由 u, v, w 构成的平行六面体的有向体积

**行列式表示**：

```
u · (v × w) = det([x, v₁, w₁; y, v₂, w₂; z, v₃, w₃])

其中 u = [x, y, z]
```

**推导**：

```
左边：u · (v × w)
右边：det([x, v₁, w₁; y, v₂, w₂; z, v₃, w₃])

按第一列展开：
= x(v₂w₃ - v₃w₂) - y(v₁w₃ - v₃w₁) + z(v₁w₂ - v₂w₁)
= [x,y,z] · (v₂w₃ - v₃w₂, v₃w₁ - v₁w₃, v₁w₂ - v₂w₁)
= u · (v × w)
```

### 对偶向量视角

**定义**：每个线性泛函 f: V → ℝ 都唯一对应一个向量 a，使得 f(u) = ⟨u, a⟩

**本例中**：

| 对象 | 身份 |
|------|------|
| f(u) = u · (v × w) | 线性泛函 |
| v × w | 该泛函的**对偶向量** |

**意义**：v × w 同时是：
- 一个向量（有方向、模长）
- 一个线性泛函的"代表"（对偶向量）

### 行列式与线性性

**函数**：

```
f([x,y,z]) = det([x, v₁, w₁; y, v₂, w₂; z, v₃, w₃])
```

**为什么是线性的？**

展开后：
```
f([x,y,z]) = x·C₁ + y·C₂ + z·C₃ = [x,y,z] · [C₁, C₂, C₃]
```

其中 C₁, C₂, C₃ 是常数（因为 v, w 固定）。

这本质上是**点积**，点积天然就是线性的。

**线性验证**：

```
f(a + b) = (a + b) · C = a·C + b·C = f(a) + f(b) ✓
f(ka) = (ka) · C = k(a·C) = k·f(a) ✓
```

### 三维矩阵行列式展开

**3×3 矩阵**：

```
| a₁ a₂ a₃ |
| b₁ b₂ b₃ |
| c₁ c₂ c₃ |
```

**按第一行展开**：

```
det = a₁·(b₂c₃ - b₃c₂) - a₂·(b₁c₃ - b₃c₁) + a₃·(b₁c₂ - b₂c₁)
```

**符号规则**（(-1)^(i+j)）：

| | j=1 | j=2 | j=3 |
|---|---|---|---|
| i=1 | + | - | + |
| i=2 | - | + | - |
| i=3 | + | - | + |

## 13.2 叉积的应用

### 1. 求法向量（计算机图形学）

```
已知三角形三点 P₁, P₂, P₃
边向量：a = P₂ - P₁,  b = P₃ - P₁
法向量：n = a × b
```

用于光照计算、判断面的朝向。

### 2. 判断点在三角形内外

```
P 在三角形 ABC 内 ⟺ 
  (AB × AP), (BC × BP), (CA × CP) 方向相同
```

### 3. 计算面积

```
三角形面积 = |AB × AC| / 2
```

### 4. 物理应用：力矩

```
力矩 τ = r × F
r = 力臂向量
F = 力向量
```

### 5. 物理应用：洛伦兹力

```
F = qv × B
带电粒子在磁场中受力
```

### 6. 判断两向量方向

```
a × b 的 z 分量：
  > 0 → b 在 a 左侧（逆时针）
  < 0 → b 在 a 右侧（顺时针）
  = 0 → 共线
```

用于多边形点序判断、凸包算法。

> **总结**：叉积本质是"垂直性探测器"——结果向量垂直于输入的两个向量，模长反映面积，方向反映旋转方向。

## 13.3 卷积定理（时域与频域）

### 核心概念

**卷积定理**：时域中的卷积等价于频域中的乘积

```
时域：f(t) * g(t)  ←→  频域：F(ω)·G(ω)
```

| 时域 | 频域 |
|------|------|
| 卷积 * | 乘法 · |
| 复杂度 O(n²) | 复杂度 O(n log n) |

### 数学公式

**正向**：
```
F{f * g} = F{f} · F{g}
```

**逆向**：
```
f * g = F⁻¹{F{f} · F{g}}
```

### 代码验证

```python
import numpy as np

# 信号和卷积核
signal = np.array([1, 2, 3, 4, 5], dtype=float)
kernel = np.array([1, 0, -1], dtype=float)

# 方法1：直接时域卷积
conv_time = np.convolve(signal, kernel)

# 方法2：频域乘法
n = len(signal) + len(kernel) - 1  # 补零长度
F = np.fft.fft(signal, n)
G = np.fft.fft(kernel, n)
conv_freq = np.fft.ifft(F * G).real

# 验证：结果完全相同
print(conv_time)    # [ 1.  2.  2.  2.  2. -4. -5.]
print(conv_freq)    # [ 1.  2.  2.  2.  2. -4. -5.]
```

### 复杂度对比

| 信号长度 | 时域卷积 O(n²) | 频域方法 O(n log n) | 加速比 |
|---------|----------------|---------------------|--------|
| 1,000 | 1,000,000 | 9,965 | 100x |
| 10,000 | 100,000,000 | 132,877 | 753x |
| 100,000 | 10,000,000,000 | 1,660,964 | 6,020x |

### 应用场景

| 领域 | 应用 |
|------|------|
| **深度学习** | CNN 卷积加速（FFT 替代空间卷积） |
| **信号处理** | 快速滤波（音频、图像去噪） |
| **图像处理** | 大尺寸卷积核高效实现 |
| **通信系统** | 信道卷积频域均衡 |
| **概率论** | 独立随机变量和的密度 = 各密度卷积 |
| **数值计算** | 多项式乘法 O(n log n) 实现 |

### 直觉理解

```
时域                              频域

f(t) ____                         |F(ω)|
    |    |                           *
    |    |                          * *
    |____|                         *   *

g(t) ____                         |G(ω)|
    |    |                           *
    |    |                          * *
    |____|                         *   *

          卷积                              乘法
            ↓                                ↓

f*g   _____                         |F·G|
     /    \                            *
    /      \                          * *
   /        \                        *   *
  /          \____

    时域卷积 = 频域乘法（结果相同）
```

### 关键要点

1. **补零**：需补零至 `len(f) + len(g) - 1`，避免循环卷积
2. **等价性**：时域卷积 ↔ 频域乘法，结果完全相同
3. **加速**：大信号处理时，频域方法快得多
4. **双向**：时域乘法 ↔ 频域卷积也成立

## 15. 范数（Norm）

### 定义

**范数**是衡量向量"大小"的一种方式，将向量映射为一个非负实数。

### 三种常用范数

以向量 **v = [3, -4]** 为例：

| 范数 | 公式 | 计算 | 结果 |
|------|------|------|------|
| **L1**（曼哈顿距离） | Σ\|vᵢ\| | \|3\| + \|-4\| | 7 |
| **L2**（欧几里得距离） | √(Σvᵢ²) | √(9 + 16) = √25 | 5 |
| **L∞**（最大范数） | max(\|vᵢ\|) | max(3, 4) | 4 |

### 几何直觉

```
v = [3, -4]  →  平面上从原点到 (3, -4) 的箭头

L1: 沿网格走（横竖走）的距离     → 7
L2: 直线距离                    → 5
L∞: 横竖两个方向中更远的那个     → 4
```

### 矩阵的范数（Frobenius 范数）

```
A = [[1, 2],
     [3, 4]]

‖A‖_F = √(1² + 2² + 3² + 4²) = √30 ≈ 5.48
```

### NumPy 实现

```python
import numpy as np

v = np.array([3, -4])
np.linalg.norm(v, ord=1)        # 7.0
np.linalg.norm(v, ord=2)        # 5.0（默认 L2）
np.linalg.norm(v, ord=np.inf)   # 4.0
```

## 16. L1/L2 范数与机器学习正则化

### 核心问题

训练模型时，**过拟合** = 模型过度依赖某些特征，权重很大，对训练数据拟合得太用力。

正则化通过在损失函数中加入"惩罚项"来约束权重：

```
总损失 = 原始损失 + λ × 惩罚项
```

### L1 正则化 → 稀疏解（特征选择）

**惩罚项**：λ × Σ|wᵢ|

**为什么能产生稀疏解（很多权重精确为 0）？**

**几何直觉**：

```
        L1 菱形（有尖角）           L2 圆形（光滑）
           ▲
          /|\                        ╭───╮
         / | \  ← 椭圆等高线        ╱     ╲
        / ⭐\    碰到尖角           │  ⭐  │ ← 解落在圆弧上
       /____|____\                  ╰───╯    （w1, w2 都不为 0）

  菱形尖角在坐标轴上                圆没有尖角
  解容易落在角上 → 某些 w=0        解很难恰好落在轴上
```

L1 约束区域是**菱形**，尖角在坐标轴上，损失函数的椭圆等高线更可能碰到角 → 某些权重恰好为 0。

**梯度直觉**：

```
L1 梯度 = ±1（恒定，不管权重大小）
L2 梯度 = 2w（权重越大推力越大，越小推力越小）
```

- L2 对很小的权重几乎不推 → 权重趋近 0 但到不了 0
- L1 对小权重也用同样的力 → 直接推到 0 → **精确稀疏** → **特征选择**

### L2 正则化 → 权重衰减（防止过拟合）

**惩罚项**：λ × Σwᵢ²

**为什么能防止过拟合？**

```
总损失 = 原始损失 + λ × Σ(wᵢ²)

→ 惩罚大的权重，让所有权重保持较小
```

效果：
- **权重小 → 模型平滑**：每个特征只贡献一点点，不会因某个特征剧烈变化
- **所有特征都参与**：没有权重被归零，只是被压小，模型更均衡
- **L2 可微**：w² 在 0 处可微，优化过程稳定

### L1 vs L2 对比

| | L1 正则化 | L2 正则化 |
|---|---|---|
| 惩罚项 | λ × Σ\|wᵢ\| | λ × Σwᵢ² |
| 几何形状 | 菱形（有尖角） | 圆形（光滑） |
| 梯度行为 | 恒定力度推向 0 | 力度随权重缩小而减弱 |
| 结果 | 很多权重**精确为 0** | 权重都**很小但不为 0** |
| 效果 | 特征选择（删特征） | 权重衰减（压特征） |
| 适合场景 | 特征多且稀疏 | 防止过拟合 |

> **一句话总结**：L1 用恒力把小权重直接推到 0，L2 用弹性力把大权重拉小但不归零。
