# 贝叶斯定律与复数乘法

## 一、贝叶斯定律

### 1.1 核心公式

```
P(A|X) × P(X) = P(X|A) × P(A)
```

**本质：联合概率的对称性**

### 1.2 几何理解

```
联合概率 P(A ∩ X)：
┌─────────────────────────────┐
│         全集 Ω              │
│    ┌─────────────┐         │
│    │      X      │         │
│    │   ┌───┐     │         │
│    │   │ A∩X│     │  ← 这个阴影区域
│    │   └───┘     │         │
│    └─────────────┘         │
└─────────────────────────────┘
「A 和 X 重叠的部分」

条件概率 P(A|X)：
┌─────────────────────────────┐
│         全集 Ω              │
│    ┌─────────────┐         │
│    │      X      │ ← 只看这个区域
│    │   ┌───┐     │         │
│    │   │ A∩X│     │ ← 占 X 的比例
│    │   └───┘     │         │
│    └─────────────┘         │
└─────────────────────────────┘
「A∩X 占 X 的比例」
```

### 1.3 两种计算路径

**路径1：先看 X，再看 A**
```
P(A|X) × P(X) = P(A 在 X 中的比例) × P(X 的大小) = P(A ∩ X)
```

**路径2：先看 A，再看 X**
```
P(X|A) × P(A) = P(X 在 A 中的比例) × P(A 的大小) = P(X ∩ A)
```

**结果相同：A ∩ X 的面积！**

### 1.4 具体例子：疾病检测

```
A = 患病，X = 阳性

已知：
P(A) = 0.01（患病率）
P(X|A) = 0.95（灵敏度）
P(X|¬A) = 0.05（假阳性率）

求：P(A|X) = ?
```

**计算过程**：
```
P(X) = P(X|A)P(A) + P(X|¬A)P(¬A)
     = 0.95×0.01 + 0.05×0.99
     = 0.059

P(A|X) = P(X|A)×P(A) / P(X)
       = 0.95×0.01 / 0.059
       ≈ 0.161（16.1%）
```

### 1.5 条件概率 vs 联合概率

| 概念 | 公式 | 含义 |
|------|------|------|
| **联合概率** | P(A ∩ X) | A 和 X **同时发生** |
| **条件概率** | P(A\|X) | 已知 X 发生，A 发生的概率 |

**等式两边相等，但 P(A|X) ≠ P(X|A)**

### 1.6 贝叶斯定律 + 混淆矩阵

| 指标 | 公式 | 概率表示 |
|------|------|----------|
| 灵敏度 | TP/(TP+FN) | P(X\|A) |
| 特异度 | TN/(TN+FP) | P(¬X\|¬A) |
| 阳性预测值 | TP/(TP+FP) | P(A\|X) |
| 阴性预测值 | TN/(TN+FN) | P(¬A\|¬X) |

**贝叶斯定律连接了「原因→结果」和「结果→原因」两个方向！**

## 二、复数乘法与三角函数

### 2.1 核心关系

```
复数乘法 = 模长相乘，辐角相加
         ↓
    直接推导出三角函数和角公式
```

### 2.2 三角函数和角公式

```
cos(a+b) = cos(a)·cos(b) - sin(a)·sin(b)
sin(a+b) = cos(a)·sin(b) + cos(b)·sin(a)
```

### 2.3 推导过程

**复数的极坐标形式**：
```
z = r(cos θ + i sin θ) = re^(iθ)
```

**复数乘法**：
```
z₁ = cos α + i sin α
z₂ = cos β + i sin β

z₁ × z₂ = (cos α + i sin α)(cos β + i sin β)
        = cos α cos β + i cos α sin β + i sin α cos β + i² sin α sin β
        = (cos α cos β - sin α sin β) + i(cos α sin β + sin α cos β)
```

**对比两种结果**：
```
方法1（极坐标）：z₁ × z₂ = cos(α+β) + i sin(α+β)
方法2（直接算）：z₁ × z₂ = (cos α cos β - sin α sin β) + i(cos α sin β + sin α cos β)

比较实部：cos(α+β) = cos α cos β - sin α sin β ✓
比较虚部：sin(α+β) = cos α sin β + sin α cos β ✓
```

### 2.4 FOIL 方法：复数乘法

```
(3 + 4i) × (2 + 3i)

FOIL = First, Outer, Inner, Last
```

| 步骤 | 计算 | 结果 |
|------|------|------|
| **F**irst（首项） | 3 × 2 | 6 |
| **O**uter（外项） | 3 × 3i | 9i |
| **I**nner（内项） | 4i × 2 | 8i |
| **L**ast（末项） | 4i × 3i | 12i² = -12 |

**合并结果**：
```
= 6 + 9i + 8i + (-12)
= (6 - 12) + (9 + 8)i
= -6 + 17i
```

### 2.5 欧拉公式统一

```
e^(iθ) = cos θ + i sin θ

e^(i(α+β)) = e^(iα) × e^(iβ)

左边：cos(α+β) + i sin(α+β)
右边：(cos α + i sin α)(cos β + i sin β)

展开右边 → 得到和角公式
```

## 三、两者联系

| 贝叶斯定律 | 复数乘法 |
|------------|----------|
| P(A\|X) × P(X) = P(X\|A) × P(A) | z₁ × z₂ = r₁r₂e^(i(θ₁+θ₂)) |
| 联合概率对称性 | 辐角相加 |
| 连接因果方向 | 连接代数与几何 |

**两者都是「对称性」的体现：**
- 贝叶斯：联合概率的对称性
- 复数乘法：旋转的对称性
