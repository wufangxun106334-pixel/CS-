# 损失函数

损失函数用来衡量模型预测结果和真实标签之间的差异。损失越小，说明模型预测越接近真实值。

## 交叉熵损失

交叉熵损失常用于分类问题，尤其是逻辑回归和神经网络分类。

### 二分类形式

如果真实标签 `y ∈ {0,1}`，模型预测正类概率为 `p`，则交叉熵损失为：

```text
L = -[y log(p) + (1 - y) log(1 - p)]
```

### 含义

- 当 `y = 1` 时，损失变为 `-log(p)`，模型越接近输出 1，损失越小。
- 当 `y = 0` 时，损失变为 `-log(1-p)`，模型越接近输出 0，损失越小。
- 如果模型对错误答案非常自信，损失会迅速变大。

### 例子

假设真实标签是 `y = 1`。

- 如果模型预测 `p = 0.9`：

```text
L = -log(0.9) ≈ 0.105
```

- 如果模型预测 `p = 0.1`：

```text
L = -log(0.1) ≈ 2.303
```

可以看到，预测越错且越自信，惩罚越大。

## 和逻辑回归的关系

逻辑回归通常假设样本标签服从伯努利分布，并通过最大似然估计来学习参数。

对于单个样本，似然可以写成：

```text
P(y | x) = p^y (1 - p)^(1-y)
```

对所有样本取连乘后再取对数，最大化对数似然，就等价于最小化负对数似然，也就是交叉熵损失。

所以逻辑回归常用的损失函数不是平方损失，而是交叉熵损失。

## 一句话记忆

交叉熵损失就是：真实标签和预测概率越一致，损失越小；预测得越自信但越错，损失越大。
