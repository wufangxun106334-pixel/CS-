## 典型题目模板：统计大写字母

### 题目要求

```text
编写 RISC-V 汇编程序，统计字符串中的大写字母数量
- 字符串存储在内存中
- 字符串由标准 ASCII 字符组成
- 字符串以句点 '.' 结尾
- 将最终计数结果存储为 32-bit word
```

### ASCII 值速查

| 字符 | 十进制 | 十六进制 | 二进制 |
|------|--------|----------|--------|
| `.` (终止符) | 46 | 0x2E | 0010 1110 |
| `A` (大写起始) | 65 | 0x41 | 0100 0001 |
| `Z` (大写结束) | 90 | 0x5A | 0101 1010 |
| `a` (小写起始) | 97 | 0x61 | 0110 0001 |
| `z` (小写结束) | 122 | 0x7A | 0111 1010 |

### 完整程序模板

```asm
.data
str:    .ascii "COMP 30660."    # 测试字符串
count:  .word 0                  # 存储结果

.text
.globl main
main:
    # 初始化寄存器
    la   t0, str        # t0 = 字符串指针
    li   t1, 0          # t1 = 计数器
    li   t2, '.'        # t2 = 终止符 (46)
    li   t3, 'A'        # t3 = 大写字母下界 (65)
    li   t4, 'Z'        # t4 = 大写字母上界 (90)

loop:
    lb   t5, 0(t0)      # 加载当前字符到 t5
    beq  t5, t2, done   # 如果是 '.'，跳转到 done

    # 范围检查：'A' <= char <= 'Z'
    blt  t5, t3, next   # 如果 char < 'A'，跳过
    blt  t4, t5, next   # 如果 'Z' < char，跳过

    # 如果到这里，说明 'A' <= char <= 'Z'
    addi t1, t1, 1      # count++

next:
    addi t0, t0, 1      # 指针移动到下一个字节
    j    loop           # 返回循环开始

done:
    la   t6, count      # t6 = count 变量地址
    sw   t1, 0(t6)      # 存储最终计数

    # 退出程序
    li   a7, 10
    ecall
```

## 程序逻辑分解

### 1. 初始化阶段

```asm
la   t0, str        # 指针指向字符串起始
li   t1, 0          # 计数器清零
li   t2, '.'        # 加载终止条件
li   t3, 'A'        # 加载范围下界
li   t4, 'Z'        # 加载范围上界
```

**关键点：**
- 使用 `la` (load address) 获取字符串地址
- 使用 `li` (load immediate) 初始化常量
- 字符常量会被汇编器转换为对应的 ASCII 值

### 2. 循环体结构

```text
loop:
    1. 加载当前字符 (lb)
    2. 检查终止条件 (beq)
    3. 范围检查 (blt × 2)
    4. 满足条件则计数 (addi)
    5. 指针递增 (addi)
    6. 跳回循环开始 (j)
```

### 3. 范围检查技巧

```asm
blt  t5, t3, next   # if (char < 'A') goto next
blt  t4, t5, next   # if ('Z' < char) goto next
# 如果两个条件都不满足，说明 'A' <= char <= 'Z'
addi t1, t1, 1      # 执行计数
```

**为什么用两个 `blt`？**
- 第一个 `blt t5, t3, next`：检查 `char < 'A'`
- 第二个 `blt t4, t5, next`：检查 `'Z' < char`（等价于 `char > 'Z'`）
- 如果都不跳转，说明 `'A' <= char <= 'Z'`

**注意：** 样卷参考表可能只提供 `beq`, `bne`, `blt`, `bge`，不提供 `bgt`。因此用 `blt t4, t5` 代替 `bgt t5, t4`。

### 4. 字节访问指令

```asm
lb   t5, 0(t0)      # Load Byte (符号扩展)
```

**为什么用 `lb` 而不是 `lbu`？**
- ASCII 字符值都在 0-127 范围内（最高位为 0）
- `lb` 和 `lbu` 对于 ASCII 字符结果相同
- 通常字符处理用 `lbu` 更安全（零扩展）

**改进版本（使用 `lbu`）：**
```asm
lbu  t5, 0(t0)      # Load Byte Unsigned (零扩展)
```

## 易错点与调试技巧

### 易错点 1：忘记指针递增

```asm
# 错误：忘记 addi t0, t0, 1
loop:
    lb   t5, 0(t0)
    beq  t5, t2, done
    # ... 处理逻辑 ...
    j    loop           # 死循环！指针没有移动
```

**正确做法：** 每次循环结束前必须 `addi t0, t0, 1`

### 易错点 2：范围检查逻辑错误

```asm
# 错误：使用 bge 而不是 blt
bge  t5, t3, check_upper   # if (char >= 'A')
check_upper:
    bge  t4, t5, increment # if ('Z' >= char)
    # 这样写逻辑正确但不够简洁
```

**推荐做法：** 用两个 `blt` 排除不符合条件的情况

### 易错点 3：终止条件判断位置错误

```asm
# 错误：先处理再检查终止
loop:
    lb   t5, 0(t0)
    # ... 范围检查和计数 ...
    beq  t5, t2, done   # 终止符也被处理了！
```

**正确做法：** 加载字符后立即检查终止条件

### 易错点 4：存储结果时地址错误

```asm
# 错误：直接用标签作为地址
sw   t1, count      # 语法错误！count 是标签不是寄存器

# 正确：先加载地址
la   t6, count
sw   t1, 0(t6)
```

## 性能优化技巧

### 优化 1：减少立即数加载

```asm
# 原始版本：每次循环都加载常量
loop:
    li   t2, '.'
    li   t3, 'A'
    li   t4, 'Z'
    # ...

# 优化版本：在循环外加载一次
main:
    li   t2, '.'
    li   t3, 'A'
    li   t4, 'Z'
loop:
    # 直接使用 t2, t3, t4
```

### 优化 2：使用寄存器别名提高可读性

```asm
# 定义别名（注释形式）
# ptr = t0 (字符串指针)
# cnt = t1 (计数器)
# term = t2 (终止符)
# lower = t3 (下界)
# upper = t4 (上界)
# ch = t5 (当前字符)
```

### 数组逐项比较模板

典型任务: 比较两个数组的对应元素，遇到不同则返回 0，全部相同则返回 1。

```asm
.data
array1: .word 1, 2, 3
array2: .word 1, 2, 3
length: .word 3
result: .word 0

.text
main:
    la   t0, array1       # t0 = array1 指针
    la   t1, array2       # t1 = array2 指针
    la   t2, length
    lw   t2, 0(t2)        # t2 = length
    li   t3, 0            # t3 = index

loop:
    bge  t3, t2, equal    # index >= length -> 全部相同
    lw   t4, 0(t0)        # t4 = array1[i]
    lw   t5, 0(t1)        # t5 = array2[i]
    bne  t4, t5, not_equal
    addi t0, t0, 4        # word 指针前进 4 bytes
    addi t1, t1, 4
    addi t3, t3, 1
    j    loop

equal:
    li   t6, 1
    j    save

not_equal:
    li   t6, 0

save:
    la   t0, result
    sw   t6, 0(t0)
```

### 函数化版本模板

当题目要求“写一个函数”或需要复用比较逻辑时，把返回值放在 `a0`，调用方用 `jal` 跳转。

```asm
main:
    la   a0, array1       # 参数1: array1 地址
    la   a1, array2       # 参数2: array2 地址
    lw   a2, length       # 参数3: length
    jal  ra, compare_arrays
    la   t0, result
    sw   a0, 0(t0)
    j    exit

compare_arrays:
    li   t0, 0            # index

loop:
    bge  t0, a2, equal
    lw   t1, 0(a0)
    lw   t2, 0(a1)
    bne  t1, t2, not_equal
    addi a0, a0, 4
    addi a1, a1, 4
    addi t0, t0, 1
    j    loop

equal:
    li   a0, 1
    jalr x0, 0(ra)

not_equal:
    li   a0, 0
    jalr x0, 0(ra)
```

### 数组题与字符串题的共同结构

| 结构 | 字符串处理 | 数组处理 |
|------|------------|----------|
| 读取指令 | `lb` / `lbu` | `lw` |
| 存储指令 | `sb` 或最终 `sw count` | `sw result` |
| 指针步长 | `addi ptr, ptr, 1` | `addi ptr, ptr, 4` |
| 终止条件 | 终止字符 / null / 固定字符 | index 与 length 比较 |
| 常见分支 | ASCII 范围判断 | 元素相等/不等判断 |
| 返回值 | count 或转换后的字符串 | `1` 表示相同，`0` 表示不同 |

### 高频易错点

- Word 数组每次指针加 `4`，不是加 `1`。
- `length` 是元素个数，不是字节数。
- 比较前必须先 `lw` 取出元素，不能直接比较两个地址寄存器。
- 函数版本中返回值放 `a0`，不是随便放 `t*`。
- 使用 `jalr x0, 0(ra)` 返回时不会覆盖任何目标寄存器。
