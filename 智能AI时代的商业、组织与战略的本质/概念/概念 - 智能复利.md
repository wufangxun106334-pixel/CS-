# 智能复利

> **AI 智能体系统会随着增长而变得更智能的现象——增长直接增强能力，能力推动增长。**

**出处**：[[02 - 智能复利和黑洞效应]]

## 要点

**缘起**：AI 突破了「高质量智力始终极其稀缺」这一约束，普通认知能力的供给接近无穷。

**关键反差**：传统资产 使用 = 损耗；AI 系统 使用 = 学习 + 增值。

**飞轮**：执行任务 → 获得反馈 → 反馈进入优化 → 能力增强 → 可处理更复杂任务 → 更高质量反馈

**重要限定**：智能复利是一种**价值创造机制，而不是优势生成机制**（见两道转化）。
