# 三个基础设施判据

> **可计量性、可组合性、可规模化使用。三者同时成立时，AI 才具备基础设施性质。**

**出处**：[[01 - AI 产业化的展开：从智能体爆发到系统级重构]]

## 要点

可计量 → Token 成为统一能力单位，具备工业化条件
可组合 → 开发者可在已有能力之上组织新系统
可规模化使用 → 用量在开发者与用户中持续增长

→ 人类第一次把智力本身转化成一种可以被大规模调用的能力
