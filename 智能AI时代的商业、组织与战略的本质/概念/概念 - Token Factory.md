# Token Factory

> **黄仁勋在 GTC 2026 提出的概念：未来的数据中心本质上在生产 Token，就像工业时代的炼油厂持续输出能源。**

**出处**：[[01 - AI 产业化的展开：从智能体爆发到系统级重构]]

## 要点

意义：把原本抽象的大模型能力，转化为一种可以持续生产、持续消耗的资源。
与奥特曼的表述互相印证：OpenAI 所提供的并不是某一个具体应用，而是 Token 本身。
