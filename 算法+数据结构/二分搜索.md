# 二分搜索

## 1. 前提

二分搜索要求数组已经有序，通常是升序数组。

```python
a = [1, 2, 4, 4, 4, 6, 7]
```

如果输入没有保证有序，需要先排序：

```python
a.sort()
```

---

## 2. 普通二分 vs 边界二分

### 普通二分

普通二分用于判断某个值 `x` 是否存在。

特点：

```text
碰到 a[mid] == x 就可以直接返回
```

```python
def binary_search(a, x):
    left, right = 0, len(a) - 1

    while left <= right:
        mid = (left + right) // 2

        if a[mid] == x:
            return True
        elif a[mid] < x:
            left = mid + 1
        else:
            right = mid - 1

    return False
```

### 边界二分

边界二分不是为了立刻找到某个 `x`，而是为了找到分界线。

例如：

```text
< x | >= x
<= x | > x
```

所以即使遇到 `a[mid] == x`，也不一定马上返回，而是继续逼近边界。

---

## 3. `while left <= right` 模板

搜索区间是闭区间：

```text
[left, right]
```

结束条件：

```text
left > right
```

结束时通常有：

```text
left = right + 1
```

### 找第一个 `>= x`

划分：

```text
< x | >= x
  r    l
```

```python
def lower_bound(a, x):
    left, right = 0, len(a) - 1

    while left <= right: #取等
        mid = (left + right) // 2

        if a[mid] < x:
            left = mid + 1 #收缩边界
        else:
            right = mid - 1 # 收缩边界

    return left
```

结束后：

```text
left = 第一个 >= x 的位置
right = 最后一个 < x 的位置
```

如果 `left == len(a)`，说明所有元素都 `< x`。

### 找最后一个 `<= x`

划分：

```text
<= x | > x
   r    l
```

```python
def last_le(a, x):
    left, right = 0, len(a) - 1

    while left <= right:
        mid = (left + right) // 2

        if a[mid] <= x:  # 取等
            left = mid + 1
        else:
            right = mid - 1

    return right
```

结束后：

```text
right = 最后一个 <= x 的位置
left = 第一个 > x 的位置
```

如果 `right == -1`，说明没有元素 `<= x`。

## 4. `while left < right` 模板

这套模板通常使用左闭右开区间：

```text
[left, right)
```

初始化：

```python
left = 0
right = len(a)
```

结束条件：

```text
left == right
```

### 找第一个 `>= x`

```python
def lower_bound(a, x):
    left, right = 0, len(a)

    while left < right: # 不取等
        mid = (left + right) // 2

        if a[mid] < x: #不取等
            left = mid + 1 # 收缩边界
        else:
            right = mid

    return left
```

解释：

```text
如果 a[mid] < x，说明 mid 在左半区，答案在右边。
如果 a[mid] >= x，说明 mid 在右半区，但可能不是第一个，所以保留 mid，令 right = mid。
```

结束时：

```text
left = right = 第一个 >= x 的位置
```

### 找第一个 `> x`

```python
def upper_bound(a, x):
    left, right = 0, len(a)

    while left < right:
        mid = (left + right) // 2

        if a[mid] <= x:
            left = mid + 1
        else:
            right = mid

    return left
```

结束时：

```text
left = right = 第一个 > x 的位置
```

## 5. 四种常见边界

基于 `lower_bound` 和 `upper_bound`：

```python
def lower_bound(a, x):
    left, right = 0, len(a)

    while left < right:
        mid = (left + right) // 2

        if a[mid] < x:  #找到第一个x停止
            left = mid + 1
        else:
            right = mid

    return left


def upper_bound(a, x):
    left, right = 0, len(a)

    while left < right:
        mid = (left + right) // 2

        if a[mid] <= x: #找到最后一个x停止
            left = mid + 1
        else:
            right = mid

    return left
```

### 第一个 `>= x`

```python
pos = lower_bound(a, x)
```

### 第一个 `> x`

```python
pos = upper_bound(a, x)
```

### 最后一个 `< x`

```python
pos = lower_bound(a, x) - 1
```

### 最后一个 `<= x`

```python
pos = upper_bound(a, x) - 1
```

## 6. 插入位置

如果要把 `x` 插入数组并保持升序：

### 插到相同元素前面

```python
pos = lower_bound(a, x)
```

例如：

```text
a = [1, 2, 4, 4, 6]
x = 4
pos = 2
```

### 插到相同元素后面

```python
pos = upper_bound(a, x)
```

例如：

```text
a = [1, 2, 4, 4, 6]
x = 4
pos = 4
```

---

## 7. 统计某个数出现次数

思路：

```text
次数 = 第一个 > x 的位置 - 第一个 >= x 的位置
```

代码：

```python
def count_x(a, x):
    return upper_bound(a, x) - lower_bound(a, x)
```

例子：

```text
a = [1, 2, 4, 4, 4, 6, 7]
x = 4

lower_bound(a, 4) = 2
upper_bound(a, 4) = 5
次数 = 5 - 2 = 3
```

## 8. 处理重复元素

普通二分如果遇到重复元素，只能找到任意一个位置。

边界二分可以找到完整范围：

```python
def range_of_x(a, x):
    first = lower_bound(a, x)
    last = upper_bound(a, x) - 1

    if first <= last:
        return first, last
    return -1, -1
```

例子：

```text
a = [1, 2, 4, 4, 4, 6, 7]
x = 4

first = 2
last = 4
```

所以所有 `4` 的范围是：

```text
[2, 4]
```

## 9. 关于 `left`、`right`、`mid`

### `while left <= right`

结束时：

```text
left = right + 1
```

`mid` 只是最后一次循环的中点，循环结束后不要用 `mid` 判断答案。

应该根据目标使用：

```text
找左边界，看 left
找右边界，看 right
```

### `while left < right`

结束时：

```text
left == right
```

答案通常就是：

```python
return left
```

---

## 10. 一句话总结

```text
如果条件把 mid 判到左半区，就移动 left，最后右边界 right 停在左半区最后一个位置。
如果条件把 mid 判到右半区，就移动 right，最后左边界 left 停在右半区第一个位置。
```

例如：

```text
<= x | > x
   r    l
```

最后：

```text
right = 最后一个 <= x
left = 第一个 > x
```

再例如：

```text
< x | >= x
  r    l
```

最后：

```text
right = 最后一个 < x
left = 第一个 >= x
```
