## 核心思想

> **栈存下标，通过 `heights[下标]` 比较值，维护单调性。**

- 栈中存的是**下标**，不是值（值可以重复，下标唯一）
- 通过 `heights[stack.peek()]` 获取值进行比较

## 单调递增栈 vs 单调递减栈

| 类型 | 条件 | 适用场景 |
|:----:|:----:|:--------|
| **递增栈**（栈底→栈顶递增） | `heights[栈顶] >= 当前` 时弹出 | 找左右第一个**更小**的元素（84. 柱状图） |
| **递减栈**（栈底→栈顶递减） | `heights[栈顶] <= 当前` 时弹出 | 找左右第一个**更大**的元素（739. 每日温度, 496. 下一个更大元素） |

## 为什么不能存值？

| 栈存什么 | 能判断单调性 | 能计算宽度 | 能处理重复值 |
|:-------:|:----------:|:---------:|:----------:|
| **值** | ✅ | ❌ 不知道下标，算不出距离 | ❌ 重复值无法区分 |
| **下标** | ✅ `heights[下标]` | ✅ `right - left - 1` | ✅ 下标唯一 |

## 为什么用 `while` 不是 `if`？

当当前元素足够大/小，比栈中**多个连续元素**都满足条件时，需要连续弹出所有相关元素。

- `if`：只处理栈顶一个元素
- `while`：把栈中所有符合条件的元素全部结算

因为当前元素是它们**共同**的右边界。

## 代码模板

### 模板 1：一次遍历（弹栈时同时确定左右边界）

```java
Deque<Integer> stack = new ArrayDeque<>();
int maxArea = 0;

for (int i = 0; i <= n; i++) {
    int curHeight = (i == n) ? 0 : heights[i];
    
    while (!stack.isEmpty() && curHeight < heights[stack.peek()]) {
        int h = heights[stack.pop()];
        int left = stack.isEmpty() ? -1 : stack.peek();
        int width = i - left - 1;
        maxArea = Math.max(maxArea, h * width);
    }
    stack.push(i);
}
```

### 模板 2：两次遍历（预计算 left[] / right[]）

```java
// 左→右：计算 left[i]（左边第一个小于 heights[i] 的下标）
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
        stack.pop();
    }
    left[i] = stack.isEmpty() ? -1 : stack.peek();
    stack.push(i);
}

// 右→左：计算 right[i]（右边第一个小于 heights[i] 的下标）
stack.clear();
for (int i = n - 1; i >= 0; i--) {
    while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
        stack.pop();
    }
    right[i] = stack.isEmpty() ? n : stack.peek();
    stack.push(i);
}

// 统一计算面积
for (int i = 0; i < n; i++) {
    maxArea = Math.max(maxArea, heights[i] * (right[i] - left[i] - 1));
}
```

### 模板 3：下一个更大元素（递减栈 + Map）

```java
Deque<Integer> stack = new ArrayDeque<>();
Map<Integer, Integer> map = new HashMap<>();

for (int num : nums2) {
    while (!stack.isEmpty() && num > stack.peek()) {
        map.put(stack.pop(), num);
    }
    stack.push(num);
}

for (int i = 0; i < nums1.length; i++) {
    nums1[i] = map.getOrDefault(nums1[i], -1);
}
```

| [739] 每日温度 | 找右边第一个更高的温度 | 递减栈 |
| [496] 下一个更大元素 I | 找右边第一个更大的元素 | 递减栈 |
| [503] 下一个更大元素 II | 循环数组找更大 | 递减栈 |
| [42] 接雨水 | 找左右边界 | 递减栈 |

## 总结

> **`pop()` = 记录完就毕业了；`peek()` = 记录完还待着不走，下个元素来又得重新记录一次（会导致死循环）。**
