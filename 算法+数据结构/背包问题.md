# 背包问题

## 核心分类

| 类型 | 物品限制 | 遍历方向 | 代表题 |
|------|----------|----------|--------|
| 01 背包 | 每个最多 1 次 | 倒序 `j--` | 416, 494, 474, 1049 |
| 完全背包 | 每个无限次 | 正序 `j++` | 322, 518, 279, 139 |

## 为什么倒序/正序？

> 计算本状态时，依赖的状态必须是对的。

- **01 背包倒序**：`dp[j]` 依赖 `dp[j-num]`（旧值），倒序保证 `dp[j-num]` 还没被更新，仍是上一轮的值
- **完全背包正序**：`dp[j]` 依赖 `dp[j-num]`（新值），正序让 `dp[j-num]` 已被本轮更新，允许同一物品多次使用

## 统一骨架

```java
dp[0] = 初始值;

for (每个物品) {
    for (int j = target; j >= 重量; j--) {  // 01: j--，完全: j++
        dp[j] = 决策(dp[j], dp[j - 重量] + 贡献);
    }
}
return dp[target];
```

## 四种变体

| 变体 | `dp[0]` | 转移方程 | 返回值 |
|------|:---:|------|:---:|
| 能否装满 | `true` | `dp[j] = dp[j] \|\| dp[j-num]` | `dp[target]` |
| 方案数 | `1` | `dp[j] = dp[j] + dp[j-num]` | `dp[target]` |
| 最大价值 | `0` | `dp[j] = max(dp[j], dp[j-w] + v)` | `dp[capacity]` |
| 最小数量 | `0`（其余 `∞`） | `dp[j] = min(dp[j], dp[j-num] + 1)` | `dp[target]` |

## 空间优化：二维 → 一维

```
二维：dp[i][j] = dp[i-1][j] || dp[i-1][j-num]   ← 只依赖上一行
滚动：dp[i%2][j] = dp[(i-1)%2][j] || ...         ← 两行交替
一维：dp[j] = dp[j] || dp[j-num]                 ← 倒序保护旧值
```

## 题号速查

### 01 背包
- **416**：能否刚好装满（boolean）
- **494**：凑出 target 的方案数（int 计数）
- **474**：二维 01 背包（两个容量维度）
- **1049**：尽量平分，转化为 01 背包

### 完全背包
- **322**：最少硬币数
- **518**：方案数
- **279**：最少完全平方数个数
- **139**：单词拆分
