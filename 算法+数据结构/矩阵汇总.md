# 矩阵（二维数组）做题思路总纲

矩阵问题是 LeetCode 中的一个大类，核心是在二维结构上进行操作、搜索或计算。

---

## 一、题型分类与核心思路

### 1. 遍历类 — 顺序即答案

**特点**：按特定顺序访问矩阵元素，常直接返回遍历结果。

| 题型 | 思路 | 例子 |
|------|------|------|
| **螺旋矩阵** | 定义上下左右四个边界，按右→下→左→上循环缩圈 | `54. Spiral Matrix` |
| **对角线遍历** | 奇偶行方向交替（偶↗奇↙），注意边界翻转 | `498. Diagonal Traverse` |
| **之字形遍历** | 行号奇偶决定遍历方向 | `103. Binary Tree Zigzag`（类比） |

**关键代码模式 — 螺旋矩阵**：

```java
int top = 0, bottom = m - 1, left = 0, right = n - 1;
while (top <= bottom && left <= right) {
    // 遍历 top 行 (left → right)
    for (int j = left; j <= right; j++) res.add(matrix[top][j]);
    top++;
    // 遍历 right 列 (top → bottom)
    for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
    right--;
    if (top <= bottom) {
        // 遍历 bottom 行 (right → left)
        for (int j = right; j >= left; j--) res.add(matrix[bottom][j]);
        bottom--;
    }
    if (left <= right) {
        // 遍历 left 列 (bottom → top)
        for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
        left++;
    }
}
```

### 2. 搜索类 — 利用有序性和剪枝

| 题型 | 思路 | 例子 |
|------|------|------|
| **搜索二维矩阵**（每行有序，每行首 > 上行尾） | 二分：先二分行，再二分列；或**以右上角为起点**（Zigzag 搜索） | `74. Search a 2D Matrix` |
| **搜索二维矩阵 II**（每行/每列分别有序） | 从**右上角**开始，`target < 当前` 左移，`target > 当前` 下移，O(m+n) | `240. Search a 2D Matrix II` |
| **单词搜索** | DFS + 回溯 + visited 剪枝，四个方向递归 | `79. Word Search` |

**为什么从右上角开始？**
- 右上角的值是**当前行最大、当前列最小**
- `target < curr` → 往左（排除整列）
- `target > curr` → 往下（排除整行）
- 每次排除一行或一列，O(m+n) 完成

### 3. 变换 / 原地操作类 — 数学规律 + 倒序处理

| 题型 | 思路 | 例子 |
|------|------|------|
| **旋转图像**（原地旋转 90°） | 先**沿对角线翻转**（转置），再**左右翻转** | `48. Rotate Image` |
| **矩阵置零** | 用**第一行和第一列**做标记位，倒序处理避免覆盖 | `73. Set Matrix Zeroes` |
| **生命游戏** | 用额外状态编码（如 2 表示 0→1, -1 表示 1→0） | `289. Game of Life` |

**旋转 90° 公式**：

```java
// 顺时针：转置 → 每行反转
// 转置
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        swap(matrix[i][j], matrix[j][i]);
// 每行反转
for (int i = 0; i < n; i++)
    reverse(matrix[i]);

// 逆时针：转置 → 每列反转
```

**矩阵置零关键 — 倒序处理**：

```java
// 1. 用第一行/列标记哪些行列需要清零
boolean firstRowZero = false, firstColZero = false;
for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;

// 用第一行/列做标记
for (int i = 1; i < m; i++)
    for (int j = 1; j < n; j++)
        if (matrix[i][j] == 0) {
            matrix[i][0] = 0;
            matrix[0][j] = 0;
        }

// 2. 从最后一行开始清零（避免破坏标记）
for (int i = m - 1; i >= 1; i--)
    for (int j = n - 1; j >= 1; j--)
        if (matrix[i][0] == 0 || matrix[0][j] == 0)
            matrix[i][j] = 0;

// 3. 处理第一行和第一列
if (firstRowZero) for (int j = 0; j < n; j++) matrix[0][j] = 0;
if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
```

### 4. 图论类 — 把矩阵看成图（BFS / DFS / 并查集）

这是矩阵题中最大也最常见的子类。**矩阵的每个格子 = 图的节点，相邻关系 = 图的边**。

| 题型 | 解法 | 例子 |
|------|------|------|
| **岛屿数量** | DFS 沉岛 / BFS / 并查集 | `200. Number of Islands` |
| **被围绕的区域** | 从边界 BFS/DFS，标记不被包围的 O | `130. Surrounded Regions` |
| **太平洋大西洋水流** | 从两边边界同时 DFS，取交集 | `417. Pacific Atlantic Water Flow` |
| **迷宫 / 网格最短路径** | BFS（从起点逐层扩散） | `1091. Shortest Path in Binary Matrix` |
| **矩阵中的最大区域 / 最大岛屿** | DFS 统计连通分量大小 | `695. Max Area of Island` |

**DFS 四方向模板**：

```java
int[][] dirs = {{-1,0}, {1,0}, {0,-1}, {0,1}}; // 上下左右

void dfs(int[][] grid, int i, int j, boolean[][] visited) {
    if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j]) return;
    visited[i][j] = true;
    for (int[] d : dirs) {
        dfs(grid, i + d[0], j + d[1], visited);
    }
}
```

**BFS 最短路径模板**：

```java
Queue<int[]> q = new LinkedList<>();
q.offer(new int[]{0, 0});
boolean[][] visited = new boolean[m][n];
visited[0][0] = true;
int steps = 0;

while (!q.isEmpty()) {
    int size = q.size();
    steps++;
    for (int k = 0; k < size; k++) {
        int[] cur = q.poll();
        if (到达终点) return steps;
        for (int[] d : dirs) {
            int ni = cur[0] + d[0], nj = cur[1] + d[1];
            if (合法(ni, nj) && !visited[ni][nj]) {
                visited[ni][nj] = true;
                q.offer(new int[]{ni, nj});
            }
        }
    }
}
```

### 5. 动态规划类 — 状态从相邻格转移

矩阵 DP 的核心：**`dp[i][j]` 依赖 `dp[i-1][j]`、`dp[i][j-1]`、`dp[i-1][j-1]` 中的一个或多个**。

| 题型 | 转移方程 | 例子 |
|------|----------|------|
| **最小路径和** | `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])` | `64. Minimum Path Sum` |
| **不同路径** | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | `62. Unique Paths` |
| **不同路径 II（有障碍）** | 同上，遇到障碍 `dp[i][j] = 0` | `63. Unique Paths II` |
| **最大正方形** | `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1` | `221. Maximal Square` |
| **矩阵中的最长递增路径** | 记忆化 DFS / DP + 拓扑排序 | `329. Longest Increasing Path` |

**关键技巧**：
- 通常可以**滚动数组**优化空间：`dp[j] = grid[i][j] + min(dp[j], dp[j-1])`
- 初始化**第一行和第一列**时单独处理

### 6. 前缀和类 — 快速求子矩阵和

**预处理**：

```java
// prefix[i+1][j+1] 表示 matrix[0..i][0..j] 的和
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        prefix[i+1][j+1] = prefix[i][j+1] + prefix[i+1][j] - prefix[i][j] + matrix[i][j];
```

**查询**子矩阵 `(r1,c1) → (r2,c2)` 的和：

```
sum = prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]
```

| 题型 | 思路 | 例子 |
|------|------|------|
| **二维区域和检索** | 二维前缀和，O(1) 查询 | `304. Range Sum Query 2D` |
| **元素和为目标值的子矩阵数量** | 枚举行区间 + 一维前缀和 + 哈希表 | `1074. Number of Submatrices That Sum to Target` |

## 二、解题步骤总结

遇到矩阵题，按以下顺序思考：

1. **矩阵做了什么事？** 遍历？搜索？变换？求值？
2. **是否有顺序/有序性可以利用？** — 右上角搜索、二分
3. **是否能转化成图问题？** — DFS/BFS 遍历连通分量
4. **是否有重叠子问题？** — DP、前缀和
5. **能否原地操作？** — 标记位、额外状态编码
6. **边界情况？** — 空矩阵、单行/单列、1x1
