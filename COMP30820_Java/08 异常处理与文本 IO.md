## 1. 三类错误

### Syntax errors

- 编译前就报错
- 如缺分号、关键字拼错

### Logical errors

- 能编译能运行，但结果错

### Runtime errors / exceptions

- 运行时发生
- 需要捕获或抛出

## 2. try-catch

来源示例：
- `lec_12_examples_1/Divide2.java`

### Demo

```java
public static int divide(int n1, int n2) throws ArithmeticException {
    if (n2 == 0)
        throw new ArithmeticException("Divisor cannot be zero");
    return n1 / n2;
}

try {
    int result = divide(x, y);
} catch (ArithmeticException ex) {

}
```

## 3. throw 和 throws

### `throw`

- 在方法体里主动抛异常

### `throws`

- 在方法签名里声明可能抛出的异常

## 5. 文本文件读取

来源示例：
- `lec_12_examples_2/ReadFileExample.java`

### Demo

```java
try (BufferedReader br = new BufferedReader(new FileReader(filename))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException ex) {
    System.out.println(ex.toString());
}
```

### 关键点

- `try-with-resources` 会自动关闭资源
- `readLine()` 到文件末尾返回 `null`

## 7. 易错点辨析

### 易错 1：`throw` 和 `throws` 是一回事

不是。

- `throw`：真的抛出
- `throws`：声明可能抛出

### 易错 2：catch 以后程序一定终止

不对。

如果异常被处理，程序可以继续执行。

### 易错 3：文件读取循环条件写成 `line != null` 就够了

不完整。

你还需要在循环里不断更新 `line`，最常见写法是：

```java
while ((line = br.readLine()) != null) { ... }
```

## 8. ⭐ 异常类层次结构

```
java.lang.Throwable
├── Error                    ← 系统级错误 (JVM)，一般不管
│   ├── StackOverflowError
│   └── OutOfMemoryError
└── Exception                ← 可处理的异常
    ├── RuntimeException     ← 未检查异常 (Unchecked)
    │   ├── ArithmeticException
    │   ├── NullPointerException
    │   ├── IndexOutOfBoundsException
    │   ├── ArrayIndexOutOfBoundsException
    │   ├── ClassCastException
    │   └── IllegalArgumentException
    └── IOException          ← 检查异常 (Checked)
        └── FileNotFoundException
```

## 9. ⭐ Checked vs Unchecked 异常

|           | Checked Exception                                | Unchecked Exception                       |
| --------- | ------------------------------------------------ | ----------------------------------------- |
| **父类**    | Exception (非 RuntimeException)                   | RuntimeException                          |
| **编译器行为** | **强制**处理（try-catch 或 throws）                     | 不强制                                       |
| **代表**    | IOException, FileNotFoundException, SQLException | NullPointerException, ArithmeticException |
| **本质**    | 外部环境导致的异常                                        | 程序逻辑错误                                    |
| **最佳实践**  | 必须处理，无法避免                                        | 应在编码时预防，不用 try-catch 处理                   |

### Demo

```java
// Checked Exception -- 编译器强制要求处理
try {
    BufferedReader br = new BufferedReader(new FileReader("file.txt"));
} catch (IOException e) {
    // 必须处理或声明 throws
}

// Unchecked Exception -- 编译器不强制
int result = 5 / 0;  // 可能抛 ArithmeticException，但不强制 try-catch
```

### 易错点

- **用 try-catch 处理 NullPointerException 是坏实践**
- 应该用 `if (obj != null)` 来预防，而不是 try-catch

```java
// ❌ 错误：用异常处理正常逻辑
try {
    System.out.println(c.toString());
} catch (NullPointerException ex) {
    System.out.println("c is null");
}

// ✅ 正确：用条件判断
if (c != null) {
    System.out.println(c.toString());
} else {
    System.out.println("c is null");
}
```

## 10. finally 执行时机

```java
try {
    // 可能抛异常的代码
} catch (Exception ex) {
    // 异常处理
} finally {
    // 无论是否异常，一定执行！
}
```

### finally 执行场景

| 情况 | finally 执行？ |
|------|---------------|
| try 正常结束 | ✅ 执行 |
| try 抛异常，catch 捕获 | ✅ 执行 |
| try 抛异常，但未被捕获 | ✅ 执行（然后异常继续向上抛） |
| try 或 catch 中有 return | ✅ **先执行 finally，再 return！** |

```java
public static int test() {
    try {
        return 1;
    } finally {
        System.out.println("finally 执行了");
    }
}
// 输出："finally 执行了"，然后返回 1
```

## 11. Java File 类常用方法

```java
File file = new File("test.txt");

file.exists()          // 文件是否存在
file.length()          // 文件大小（字节）
file.canRead()         // 是否可读
file.canWrite()        // 是否可写
file.isFile()          // 是否是普通文件
file.isDirectory()     // 是否是目录
file.isHidden()        // 是否隐藏
file.getAbsolutePath() // 获取绝对路径
file.lastModified()    // 最后修改时间戳

// 创建新文件
file.createNewFile();  // 需 try-catch IOException
```

### 注意

- `new File("test.txt")` 只是创建 Java 对象，**不会创建实际文件**
- 要创建实际文件需调用 `createNewFile()` 方法

## 12. 字节流 vs 字符流

| | 字节流 (Byte Stream) | 字符流 (Character Stream) |
|---|---|---|
| **基类** | InputStream / OutputStream | Reader / Writer |
| **适用** | 二进制文件 (图片/音频/视频) | 文本文件 |
| **示例** | FileInputStream | FileReader, BufferedReader |
| **继承关系** | — | Reader ← FileReader; Writer ← FileWriter, PrintWriter |

### 文本 I/O 常用组合

```java
// 读取文本
BufferedReader br = new BufferedReader(new FileReader("input.txt"));

// 写入文本（覆盖）
PrintWriter pw = new PrintWriter(new FileWriter("output.txt"));

// 写入文本（追加）
PrintWriter pw = new PrintWriter(new FileWriter("output.txt", true));
```

### 易错点

- FileReader 自身逐字符读，**效率低**
- BufferedReader 用缓冲区批量读，**效率高**
- try-with-resources 自动关闭资源，是最佳实践
