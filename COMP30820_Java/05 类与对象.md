## 1. 什么是类，什么是对象

- `class`：蓝图 / 模板
- `object`：类的实例

对象有：

- state：字段
- behaviour：方法

## 2. 字段、构造器、方法

来源示例：
- `lec_09_examples/Circle.java`

### Demo

```java
public class Circle {
    private double radius;
    private static int numberOfObjects = 0;

    public Circle() {
        this(1.0);
    }

    public Circle(double radius) {
        this.radius = radius;
        numberOfObjects++;
    }
}
```

## 3. `this`

### 用法 1：构造器链式调用

```java
public Circle() {
    this(1.0);
}
```

### 用法 2：区分同名参数和实例变量

```java
public void setRadius(double radius) {
    this.radius = radius;
}
```

## 4. static 成员

同样来自 `Circle.java`：

```java
private static int numberOfObjects = 0;

public static int getNumberOfObjects() {
    return numberOfObjects;
}
```

### 核心理解

- `static` 属于类
- 所有对象共享

## 5. getter / setter 和封装

封装的基本思路：

- 字段通常 `private`
- 对外通过 `getter/setter` 访问

## 6. 对象参数

来源示例：
- `lec_09_examples/TestPassObject1.java`

### Demo

```java
public static void test(Circle c) {
    c.setRadius(10);
}
```

### 现象

调用后，原对象的 `radius` 被改了。

### 原因

- 传进去的是引用值副本
- 但副本仍指向同一个 `Circle` 对象

## 8. 易错点辨析

### 易错 1：对象变量本身就是对象

不对。

对象变量通常保存的是引用。

### 易错 2：`static` 字段每个对象都有一份

不对。

`static` 字段全类共享。

### 易错 3：构造器可以随便写返回类型

不对。

构造器没有返回类型，连 `void` 也不能写。
