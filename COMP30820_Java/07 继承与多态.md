## 4. overloading vs overriding

### overloading

- 同类中方法同名
- 参数不同

### overriding

- 子类重写父类已有方法

## 8. 易错点辨析

### 易错 1：子类可以直接访问父类所有字段

不对。

如果父类字段是 `private`，子类也不能直接访问。

### 易错 2：父类引用调用方法时，一定执行父类版本

不对。

如果方法被重写，运行时会动态绑定到子类实现。

### 易错 3：向下转型总是安全

不对。

必须先确认对象真实类型，通常用 `instanceof`。

## 9. ⭐ 静态绑定 vs 动态绑定

### 对比表

| | 静态绑定 (Early Binding) | 动态绑定 (Late Binding) |
|---|---|---|
| **发生时机** | 编译时 | 运行时 |
| **适用情况** | private / static / final 方法、构造器 | 可被覆盖的实例方法 |
| **依据** | 声明类型 (reference type) | 实际类型 (object type) |
| **能否覆盖** | 不能 | 能 |

### Demo

```java
class Parent {
    public static void staticMethod() { System.out.println("Parent static"); }
    public void instanceMethod() { System.out.println("Parent instance"); }
}

class Child extends Parent {
    public static void staticMethod() { System.out.println("Child static"); }
    @Override 
    public void instanceMethod() { System.out.println("Child instance"); }
}

// ---
Parent p = new Child();
p.staticMethod();    // "Parent static"  ← 静态绑定，看声明类型！
p.instanceMethod();  // "Child instance"  ← 动态绑定，看实际类型！
```

### 易错点

- 静态方法调用看**声明类型**，实例方法调用看**实际类型**
- Sample Paper Q30 直接考此概念
- 
	**static** 方法看“**引用**类型/类名”
	实例方法才看“**实**际对象类型”

## 10. private 方法不能被覆盖

```java
class Parent {
    private void show() { System.out.println("Parent"); }
}

class Child extends Parent {
    // @Override  ← 不能加！加了编译错误（因为父类 show 不可见）
    public void show() { System.out.println("Child"); }
}

// ---
Parent p = new Child();
// p.show();  // 编译错误！Parent.show() 是 private
```

### 结论

子类中与父类 private 方法同名的方法，是两个**完全无关**的方法，不是覆盖。

## 11. static 方法不能被覆盖（只能隐藏）

```java
class Parent {
    public static void greet() { System.out.println("Hello from Parent"); }
}

class Child extends Parent {
    public static void greet() { System.out.println("Hello from Child"); }
}

// ---
Parent.greet();  // "Hello from Parent"
Child.greet();   // "Hello from Child"

Parent p = new Child();
p.greet();       // "Hello from Parent" ← 按声明类型，不是实际类型！
```

如果要调用被隐藏的父类静态方法：`Parent.greet()` 或 `super.greet()`（仅子类内部）。

## 12. ⭐ 构造函数链 (Constructor Chaining)

### 规则

1. 子类构造器 **必须** 先调用父类构造器
2. 如果没有显式写 `super()` 或 `this()`，编译器自动插入 `super()`（无参）
3. 构造顺序：从最顶层父类 → 向下到子类

### Demo

```java
class A {
    public A() { System.out.println("A"); }
}
class B extends A {
    public B() { System.out.println("B"); }     // 隐式 super()
}
class C extends B {
    public C() { System.out.println("C"); }     // 隐式 super()
}

new C();
// 输出：A  B  C（从最顶层到最底层依次构造）
```

### 如果父类没有无参构造器

```java
class Parent {
    public Parent(String name) { ... }
    // 没有无参构造器！
}
class Child extends Parent {
    public Child() {
        super("default");  // 必须显式调用！
    }
}
```

### 易错点

- 如果父类有有参构造器但没有无参构造器，子类不显式调用 `super(args)` 会**编译错误**
- 构造器的执行顺序是考试高频考点

## 13. protected 访问修饰符

| 修饰符            | 类内  | 同包  | 不同包子类 | 不同包非子类 |
| -------------- | --- | --- | ----- | ------ |
| `private`      | ✅   | ❌   | ❌     | ❌      |
| default (无修饰符) | ✅   | ✅   | ❌     | ❌      |
| `protected`    | ✅   | ✅   | ✅     | ❌      |
| `public`       | ✅   | ✅   | ✅     | ✅      |

```java
// 父类
public class Parent {
    protected int x = 10;  // 子类直接访问
    private int y = 20;    // 子类只能通过 getter 访问
}

// 子类
public class Child extends Parent {
    public void display() {
        System.out.println(x);        // ✅ protected：可以直接访问
        // System.out.println(y);     // ❌ private：需要 getY()
    }
}
```

## 14. ⭐ equals() 覆盖标准 5 步模板

### 默认的 equals (继承自 Object)

```java
// Object 类的 equals 只比较引用地址
public boolean equals(Object obj) {
    return (this == obj);
}
```

### 标准覆盖模式

```java
@Override
public boolean equals(Object obj) {
    // 1️⃣ 是否同一个引用
    if (this == obj) return true;

    // 2️⃣ 是否为 null
    if (obj == null) return false;

    // 3️⃣ 是否是同一个类（严格版用 getClass()，宽松版用 instanceof）
    if (getClass() != obj.getClass()) return false;

    // 4️⃣ 安全向下转型
    Circle other = (Circle) obj;

    // 5️⃣ 逐个比较关键字段
    return Double.compare(this.radius, other.radius) == 0;
}
```

### equals() 的三个易错点

| 错误                                              | 后果                                     |
| ----------------------------------------------- | -------------------------------------- |
| 参数写成 `equals(Circle c)` 而非 `equals(Object obj)` | **不会覆盖** Object.equals，只是重载            |
| 漏掉 `@Override` 注解                               | 编译器不会帮你检查签名错误                          |
| 使用 `==` 比较 double 字段                            | 浮点精度问题，应用 `Double.compare()` 或 epsilon |

### Demo: 类的 equals

```java
public class Intern {
    private String name;
    private double salary;

    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (obj == null || getClass() != obj.getClass()) return false;
        Intern other = (Intern) obj;
        return Math.abs(this.salary - other.salary) < 1E-14
            && Objects.equals(this.name, other.name);
    }
}
```
