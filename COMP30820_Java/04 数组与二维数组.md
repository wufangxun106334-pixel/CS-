## 8. 易错点辨析

### 易错 1：数组变量里直接存元素

不对。

数组变量存的是引用，不是整块数据本体。

### 易错 2：`list1 == list2` 就是在比较内容

不对。

数组上 `==` 比较的是是否指向同一个对象。

### 易错 3：二维数组一定是规则矩阵

不对。

Java 支持每行长度不同的 jagged array。

## 8. 数组初始化器的限制

数组初始化器 **只能在声明时使用**，不能先声明后初始化。

```java
// ✅ OK：声明 + 初始化一行完成
int[] arr = {1, 2, 3, 4, 5};

// ❌ 语法错误！不能拆开
int[] arr;
arr = {1, 2, 3, 4, 5};  // Syntax error!
```

### 正确做法

```java
int[] arr;
arr = new int[]{1, 2, 3, 4, 5};  // ✅ 用 new int[]{}
```

## 9. 数组元素默认值

创建数组后，元素会被自动初始化为默认值：

| 类型 | 默认值 |
|------|--------|
| `int[]`, `double[]`, ... (数值) | `0` / `0.0` |
| `char[]` | `'\u0000'` (空字符) |
| `boolean[]` | `false` |
| `String[]`, `Circle[]`, ... (引用类型) | `null` |

```java
int[] nums = new int[5];
System.out.println(nums[0]);   // 0

String[] strs = new String[3];
System.out.println(strs[0]);   // null
```

## 10. foreach（增强 for 循环）

### 语法

```java
for (elementType variable : arrayRefVar) {
    // 使用 variable
}
```

### Demo

```java
double[] myList = {1.9, 2.9, 3.4, 3.5};

// 遍历并打印
for (double x : myList) {
    System.out.print(x + " ");
}

// 求和
double sum = 0;
for (double x : myList) {
    sum += x;
}
```

### foreach 的限制

- **不能修改数组元素**（循环变量是拷贝）
- **不能逆序遍历**（只能从前往后）
- **不能访问索引**（不知道当前是第几个元素）

```java
// ❌ 不能用 foreach 修改数组
for (double x : myList) {
    x = x * 2;  // 只改变 x 这个局部变量，不影响数组！
}
```

### 什么时候用 foreach

| 场景 | 用 foreach? |
|------|------------|
| 遍历整个数组 | ✅ |
| 需要修改元素值 | ❌ 用 for + 索引 |
| 需要逆序遍历 | ❌ 用 for + 索引 |
| 需要索引信息 | ❌ 用 for + 索引 |

## 11. java.util.Arrays 工具类

### Arrays.sort() -- 排序

```java
import java.util.Arrays;

int[] nums = {6, 4, 1, 9, 3};
Arrays.sort(nums);
System.out.println(Arrays.toString(nums));  // [1, 3, 4, 6, 9]
```

### 字符排序用的是 Unicode 顺序

```java
char[] chars = {'a', 'A', '4', 'F', 'D', 'P'};
Arrays.sort(chars);
System.out.println(Arrays.toString(chars));
// 结果：['4', 'A', 'D', 'F', 'P', 'a']
// 因为 Unicode：数字(48-57) < 大写(65-90) < 小写(97-122)
```

### Arrays.toString() -- 打印数组

```java
int[] arr = {1, 2, 3};
System.out.println(Arrays.toString(arr));  // [1, 2, 3]
// 对比：System.out.println(arr);  →  [I@15db9742 (内存地址)
```

## 12. 线性搜索 (Linear Search)

```java
public static int linearSearch(int[] list, int key) {
    for (int i = 0; i < list.length; i++) {
        if (key == list[i])
            return i;      // 找到：返回索引
    }
    return -1;             // 未找到：返回 -1
}
```

### 示例

```java
int[] arr = {1, 4, 4, 2, 5, -3, 6, 2};
linearSearch(arr, 4);   // 返回 1（第一个匹配的位置）
linearSearch(arr, -4);  // 返回 -1（未找到）
linearSearch(arr, -3);  // 返回 5
```

## 13. 数组拷贝：浅拷贝 vs 深拷贝

### 引用赋值（不是拷贝！）

```java
int[] a = {1, 2, 3};
int[] b = a;       // b 和 a 指向同一个数组！
b[0] = 100;
System.out.println(a[0]);  // 100！a 被连带修改
```

### 正确的元素拷贝（深拷贝）

```java
int[] a = {1, 2, 3};
int[] b = new int[a.length];
for (int i = 0; i < a.length; i++) {
    b[i] = a[i];
}
b[0] = 100;
System.out.println(a[0]);  // 1（a 不受影响）
```

### 易错点

- `list2 = list1` 不是拷贝元素，是拷贝引用
- `list1 == list2` 在数组上比较的是引用地址，不是元素内容
- 要比较数组内容，需要逐个元素比较，或用 `Arrays.equals()`
