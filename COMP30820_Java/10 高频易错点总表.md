## 1. 语法与基础

- `'A'` 是 `char`，`"A"` 是 `String`
- 比较字符串内容优先用 `equals()`，不是 `==`
- `Scanner.nextInt()` 后接 `nextLine()` 容易吞掉换行

## 2. 选择与循环

- `switch` 适合离散值，不等于任何分支题都该用 `switch`
- `do-while` 至少执行一次
- sentinel value 不能和正常输入混用

## 3. 方法

- Java 只有 pass-by-value
- overloading 看参数，不看返回值
- `static` 方法不能直接访问实例字段

## 4. 数组

- 数组变量存的是引用
- `list1 == list2` 比较的是地址/引用，不是内容
- 二维数组可以是 jagged array

## 5. 类与对象

- `this(...)` 用于构造器链
- `this.field = field` 常用于解决同名遮蔽
- `static` 字段全类共享，`final` 字段一旦赋值不能改

## 6. 继承与多态

- 子类不能直接访问父类 `private` 字段
- 父类引用调用被重写方法时，会动态绑定到子类实现
- 向下转型前最好先 `instanceof`

## 7. 异常与 IO

- `throw` 是抛异常，`throws` 是声明异常
- `try-with-resources` 能自动关闭流
- 读文件循环最常见正确写法是：

```java
while ((line = br.readLine()) != null) {
    ...
}
```

## 8. 抽象类与接口

- 抽象类不能直接 `new`
- 抽象类可以有具体方法
- 接口更偏“行为能力”
- `Comparable<T>` 的 `compareTo` 返回值不是 boolean

## 9. 考前建议

优先确保你能自己写出：

1. 一个带构造器、getter/setter、`toString()` 的类
2. 一个父类 + 子类 + override 的继承例子
3. 一个 `try-catch` + 文件读写例子
4. 一个抽象类或接口的最小实现
