## 1. 这类题怎么做

考试里的循环和数组题，不要凭感觉看代码。

固定步骤：

1. 写出初始值
2. 看循环条件
3. 看循环体有没有修改控制变量
4. 看 `break` / `continue`
5. 看循环后变量是否还在作用域内
6. 对数组题，逐步写出每轮后的数组内容

## 2. `for` 结尾多分号

### 例子

```java
int i = 0;
for (i = 0; i < 10; i++);
System.out.println(i + 4);
```

### 关键点

- 分号 `;` 让这个 `for` 循环体变成空语句
- 真正打印语句在循环结束后才执行

### 推演

- 循环跑完后，`i = 10`
- 输出 `14`

## 3. `do-while` 至少执行一次

### 例子

```java
int i = 1;
do {
    i++;
    System.out.println("Java");
} while (i <= 2);
```

推演：

- 第一次进入：`i` 变成 2，打印一次
- 条件 `2 <= 2`，继续
- 第二次进入：`i` 变成 3，再打印一次
- 条件 `3 <= 2`，结束

共打印 `2` 次。

## 4. while 条件区间判断

### 例子

```java
while (n < 30 || n > 90)
    n = input.nextInt();
```

含义：

- 当 `n` 不在 `[30, 90]` 内时继续读
- 直到读到落在 `[30, 90]` 内的值才停止

## 5. 数组越界题：条件顺序很关键

### 危险例子

```java
for (int i = 0; a[i] != value && i < a.length; i++)
```

### 为什么危险

Java 计算 `&&` 时是从左到右短路。

这里先算：

```java
a[i] != value
```

如果 `i == a.length`，会先越界，再也来不及判断右边。

### 正确安全写法

```java
for (int i = 0; i < a.length && a[i] != value; i++)
```

## 6. break 后的输出题

### 典型思路

```java
for (i = 0; i < 5; i++) {
    if (x[i] > 3)
        break;
}
System.out.printf("%d ", x[i]);
```

### 做法

不要急着猜，直接追踪：

- `i = 0`，检查 `x[0]`
- `i = 1`，检查 `x[1]`
- ...
- 一旦 `x[i] > 3`，循环结束
- 循环外再看 `i` 当前停在哪

## 7. 覆盖赋值题

### 例子

```java
int[] a = {5, 4, 3, 2, 1, 0};
for (int i = a.length - 2; i >= 0; i--)
    a[i + 1] = a[i];
```

### 模板

每轮写一行：

- 初始：`[5, 4, 3, 2, 1, 0]`
- `i = 4`：把 `a[4]` 复制到 `a[5]`
- `i = 3`：把 `a[3]` 复制到 `a[4]`
- ...

最后可看出数组整体右移一位，但 `a[0]` 保持原值。

## 8. 字符串构造题

### 例子

```java
String s1 = "hello";
String s2 = "";
for (int i = 0; i < s1.length(); i += 2)
    s2 = s1.charAt(i) + s2; // 注意顺序s2 在后面,加的过程是反着的,加到前面
```

### 推演

- `i = 0`，`s2 = 'h' + "" -> "h"`
- `i = 2`，`s2 = 'l' + "h" -> "lh"`
- `i = 4`，`s2 = 'o' + "lh" -> "olh"`

结果：`olh`

## 9. 二维数组行引用替换

### 例子

```java
int[][] arr1 = new int[3][2];
int[] arr2 = {1, 2, 3};
arr1[1] = arr2;
arr1[1][0] = 10;
arr2[1] = 20;
```

### 核心理解

- `arr1[1] = arr2` 后，`arr1[1]` 和 `arr2` 指向同一个一维数组
- 所以改 `arr1[1][0]` 会影响 `arr2[0]`
- 改 `arr2[1]` 也会反映在 `arr1[1][1]`

## 10. primitive + array 同时传方法

### 典型模式

```java
public static void foo(int i, boolean[] b, char[] c) {
    i = 222;
    c = new char[4];
    b[0] = true;
    c[0] = 'a';
}
```

### 判断规则

- primitive 参数：改的是副本
- `b[0] = true`：修改的是共享数组对象
- `c = new char[4]`：只是让局部参数 `c` 改指向，不影响外部原数组引用

## 11. 易错点辨析

### 易错 1：数组题只要看最终一行

不对。

大多数输出题必须逐轮模拟。

### 易错 2：`&&` 左右顺序不影响安全性

不对。

数组边界检查必须写在左边，才能靠短路避免异常。

### 易错 3：把新数组赋给形参，就等于外部数组也换了

不对。

你只是改了局部引用副本。
