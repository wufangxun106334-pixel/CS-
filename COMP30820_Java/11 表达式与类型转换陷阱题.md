## 2. 整数除法和浮点除法

### 规则

- 只要两个操作数都是整数类型，结果就是整数除法
- 整数除法会直接截断小数部分

### 例子

```java
System.out.println(3 / 2);     // 1
System.out.println(3 / 2.0);   // 1.5
System.out.println(3.0 / 2);   // 1.5
```

### 易错点

```java
1 + r / 100 / k
```

如果 `r` 和 `k` 都是 `int`，这里会先做整数除法，精度直接丢掉。

## 3. 运算符优先级

### 记忆顺序

1. 括号
2. 单目运算
3. `* / %`
4. `+ -`
5. 比较
6. 逻辑与 `&&`
7. 逻辑或 `||`
8. 条件表达式 `?:`
9. 赋值

### 例子

```java
2.0 + 3 * 5 / 2 / 5.0
```

按顺序：

1. `3 * 5 = 15`
2. `15 / 2 = 7`，这里是整数除法
3. `7 / 5.0 = 1.4`
4. `2.0 + 1.4 = 3.4`

## 4. 强制类型转换

### 例子

```java
(int)(11.0252175 * 100) / 100
```

过程：

1. `11.0252175 * 100 = 1102.52175`
2. `(int)1102.52175 = 1102`
3. `1102 / 100 = 11`，这里又是整数除法

最终结果是 `11`。

### 易错点

- `(int)` 只截断，不四舍五入
- cast 完以后，如果再做整数除法，小数还会继续丢

## 5. 条件表达式 `?:`

### 语法

```java
condition ? value1 : value2
```

### 例子

```java
('a' <= 'b') ? 1 : 0
```

因为条件是 `true`，结果为 `1`。

## 6. 逻辑表达式

### 例子

```java
boolean a = true;
boolean b = false;
boolean c = true;
boolean result = a && !b || c && !(a && b);
```

建议考试时拆开：

1. `!b = true`
2. `a && !b = true`
3. `a && b = false`
4. `!(a && b) = true`
5. `c && true = true`
6. `true || true = true`

## 7. `i++` vs `++i`

### 后置自增

```java
int i = 0;
int j = i++;
```

- `j` 先拿旧值 `0`
- 然后 `i` 变成 `1`

### 前置自增

```java
int k = ++j;
```

- `j` 先加 1
- 再把新值赋给 `k`

### 结果推演

```java
int i = 0;
int j = i++;
int k = ++j;
```

最后：

- `i = 1`
- `j = 1`
- `k = 1`

## 8. `char` 参与算术

来源可联系：
- `HexDigit2Dec.java`

### 例子

```java
char c = 'A';
System.out.println(c + 1);
```

`char` 会先按编码转成整数参与运算。

所以：

```java
c - 'A' + 10
```

是完全合法的。

## 9. switch 中的自增陷阱

### 例子

```java
int k = 3;
char ch = 'b';
switch (++ch) {
    case 'a': k = 0; break;
    case 'b': k += 1; break;
    case 'c': k = 2;
    default: k += 4;
}
```

先看 `++ch`：

- `ch` 从 `'b'` 变成 `'c'`

所以进入 `case 'c'`：

1. `k = 2`
2. 没有 `break`
3. 继续执行 `default`
4. `k += 4`

最终：

- `k = 6`
- `ch = 'c'`

## 10. 做题模板

遇到表达式题，固定按这个顺序：

1. 标出每个变量当前值
2. 判断有没有整数除法
3. 判断有没有 cast
4. 判断有没有 `++`/`--`
5. 判断逻辑表达式的优先级
6. 对 `switch` 看是否 fall-through

## 11. 易错点辨析

### 易错 1：有 `double` 出现，前面所有除法都会自动变成浮点

不对。

表达式是逐步算的，前面如果已经做了整数除法，精度已经丢了。

### 易错 2：`(int)` 会四舍五入

不对。

它只是截断小数部分。

### 易错 3：`i++` 和 `++i` 在表达式里完全一样

不对。

单独一行时效果可能一样，但放进赋值表达式里结果经常不同。
