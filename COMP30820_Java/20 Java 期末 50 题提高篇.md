## 一、基础语法、类型与输入输出（Q1–Q5）

### Q1
以下代码的输出是什么？

```java
System.out.println(Math.round(-1.5));
System.out.println(Math.floor(-1.5));
```

A. `-1`  `-2.0`
B. `-2`  `-1.0`
C. `-1`  `-1.0`
D. `-2`  `-2.0`

<details><summary>答案</summary>
**A**

- `Math.round(-1.5)` → `-1`（向正无穷取整，不是对称四舍五入！）
- `Math.floor(-1.5)` → `-2.0`（向下取整，向负无穷）
</details>

### Q7
以下代码的输出是什么？

```java
int i = 3;
int k = ++i + i++ + ++i;
System.out.println(k);
```

A. `13`
B. `14`
C. `15`
D. `12`

<details><summary>答案</summary>
**B**

逐步拆解（按从左到右求值）：
- `++i` → i=4，值为 4
- `i++` → 值为 4，i=5
- `++i` → i=6，值为 6
- `4 + 4 + 6 = 14`
</details>

## 三、选择与循环（Q13–Q18）

### Q13
以下代码的输出是什么？

```java
int i = 0, sum = 0;
while (i < 4) {
    if (i % 3 == 0) {
        i++;
        continue;
    }
    sum += i;
    i++;
}
System.out.println(sum);
```

A. `0`
B. `3`
C. `6`
D. 死循环

<details><summary>答案</summary>
**B**

- i=0: i%3==0 → i=1, continue
- i=1: sum+=1 → sum=1, i=2
- i=2: sum+=2 → sum=3, i=3
- i=3: i%3==0 → i=4, continue
- i=4: 条件 false，退出循环

注意：如果漏掉 `continue` 前的 `i++` 就会死循环！
</details>

### Q14
以下代码的输出是什么？

注意与 Q13 对比：这里是 `for` 循环，`continue` 后仍会执行更新表达式 `i++`。

```java
int sum = 0;
for (int i = 0; i < 4; i++) {
    if (i % 3 == 0) {
        i++;
        continue;
    }
    sum += i;
}
System.out.println(sum);
```

A. `0`
B. `2`
C. `3`
D. `5`

> [!answer]- 答案：B
> `for` 循环在 `continue` 后仍执行更新表达式 `i++`，但循环体内也有一次 `i++`，导致某些轮次中 `i` 被自增两次。
>
> | 步骤 | 说明 |
> |---|---|
> | `i = 0` | 满足 `i % 3 == 0` → 循环体内 `i++`，变成 `1` → `continue` → `for` 更新表达式再执行一次，变成 `2` |
> | `i = 2` | 不满足 `i % 3 == 0` → `sum += 2`，所以 `sum = 2` → `for` 更新表达式执行，`i` 变成 `3` |
> | `i = 3` | 满足 `i % 3 == 0` → 循环体内 `i++`，变成 `4` → `continue` → `for` 更新表达式再执行一次，变成 `5` |
> | `i = 5` | `5 < 4` 为 `false`，退出循环 |
>
> 最终输出 `2`。

### Q15
以下代码的输出是什么？

```java
int i = 0;
while (i < 10);
{
    System.out.println("i is " + i);
    i++;
}
```

A. 输出 `i is 0` 到 `i is 9`
B. 输出 `i is 0`
C. 编译错误
D. 死循环，没有任何输出

>
> 由于 `i` 永远不会在这个空循环中改变，程序会陷入死循环，后面的 `{ ... }` 代码块不会被执行。

### Q16
以下代码的输出是什么？

```java
int count = 0;
for (int i = 0; i < 5; i++) {
    for (int j = 0; j <= i; j++) {
        if (j == 2) break;
        count++;
    }
}
System.out.println(count);
```

A. `8`
B. `9`
C. `10`
D. `12`

> [!answer]- 答案：B
> `break` 只跳出内层循环。逐轮追踪如下：
>
> | `i` | `j` 循环次数（break 前） | `count` 增量 |
> |---|---|---|
> | `0` | `j = 0`，`j == 2` 不触发 | `+1` |
> | `1` | `j = 0, 1`，`j == 2` 不触发 | `+2` |
> | `2` | `j = 0, 1`，`j == 2` 时 break | `+2` |
> | `3` | `j = 0, 1`，`j == 2` 时 break | `+2` |
> | `4` | `j = 0, 1`，`j == 2` 时 break | `+2` |
>
> 总数 = `1 + 2 + 2 + 2 + 2 = 9`。

```java
double num = 1;
```

### Q18

```java
int x = 6;
if (x = 5) {
```

## 四、方法（Q19–Q22）

### Q19
以下代码能否编译通过？如果能，输出是什么？

```java
public class Ambiguous {
    public static double max(int a, double b) {
        return a > b ? a : b;
    }
    public static double max(double a, int b) {
        return a > b ? a : b;
    }
    public static void main(String[] args) {
        System.out.println(max(1, 2));
    }
}
```

A. 输出 `2.0`
B. 输出 `1.0`
C. 编译错误：ambiguous invocation
D. 编译错误：duplicate method

> [!answer]- 答案：C
> `max(1, 2)` 中两个实参都是 `int`：
>
> | 候选方法 | 需要的转换 |
> |---|---|
> | `max(int, double)` | 第二个参数从 `int` 自动提升为 `double` |
> | `max(double, int)` | 第一个参数从 `int` 自动提升为 `double` |
>
> 两个重载版本的匹配程度相同，编译器无法选择，因此是 ambiguous invocation。

### Q20
以下代码的输出是什么？

```java
public static void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

public static void swapArray(int[] arr) {
    int temp = arr[0];
    arr[0] = arr[1];
    arr[1] = temp;
}

public static void main(String[] args) {
    int x = 3, y = 5;
    swap(x, y);
    System.out.println(x + "," + y);

    int[] nums = {3, 5};
    swapArray(nums);
    System.out.println(nums[0] + "," + nums[1]);
}
```

A. `5,3` 然后 `5,3`
B. `3,5` 然后 `3,5`
C. `3,5` 然后 `5,3`
D. `5,3` 然后 `3,5`

> [!answer]- 答案：C
> `swap(x, y)` 使用 pass-by-value，修改形参不影响外部变量。
>
> `swapArray(nums)` 传递的是引用副本，但副本指向同一数组对象，所以 `arr[0]` 和 `arr[1]` 的修改会影响原数组。
>
> 因此输出为：
>
> ```text
> 3,5
> 5,3
> ```

```java
public class Test {
```

### Q22

```java
public static int getSumDigits(int num) {
```

### Q28

```java
public class Circle {
```

</details>

### Q40
以下代码的输出是什么？

```java
public static int test() {
    try {
        int[] arr = new int[5];
        arr[10] = 100;
        return 1;
    } catch (ArrayIndexOutOfBoundsException e) {
        return 2;
    } catch (IndexOutOfBoundsException e) {
        return 3;
    } finally {
        System.out.print("F ");
    }
}

public static void main(String[] args) {
    System.out.println(test());
}
```

A. `F 2`
B. `2`
C. `F 3`
D. `2 F`

<details><summary>答案</summary>
**A**

`arr[10]` 抛 `ArrayIndexOutOfBoundsException`，被第一个 `catch` 捕获。`finally` 在 `return 2` 之前执行，输出 `"F "`，然后返回 `2`。

注意：`ArrayIndexOutOfBoundsException extends IndexOutOfBoundsException`，所以两个 catch 的顺序很重要——子类必须在前！
</details>
